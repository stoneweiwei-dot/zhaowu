## 1. 原畫為輸出真相

- 每幕必須一張獨立生成、獨立保存、獨立核對的直版 9:16 原創畫作；不可從九宮格或拼貼裁切、放大來充數。
- 首選 ChatGPT 原生圖片生成的實際原畫；其他工具生成、重繪或替代必須得到站主另外明確授權。不可使用不明來源、第三方未授權圖片、假裝原創的素材。
- **不要將程式 SVG 漸層／幾何線條／文字框當成插畫**；真正的 SVG 圖表僅可用於明確的資訊圖表需求。
- 圖像需要符合《借星》故事九幕，人物一致性、場景、情緒、光影與構圖各有敘事；保留宋式山水與高完成度藝術質感，避免制式 AI 模板。
- 原畫 PNG 優先永久保存且不可覆寫；網站可使用同畫面壓縮 WebP/AVIF 衍生圖，保留原圖可追溯路徑、SHA-256、原尺寸及生成/使用權證據。不得用有損低品質縮圖反向覆蓋原圖。

## 3. 可執行發布流程（唯一途徑）

1. **先核對資產**：列出九張原生生成原圖，逐張人工看圖；核對 9:16、畫面完整、中文正確、人物與九幕相符、著作權及來源。缺任一張不得宣稱九張完成。
2. **保存並上傳**：產生可長期讀取的本地 WebP/AVIF 與原始 PNG，建立 manifest（識別符、檔名、像素、SHA-256、來源/生成證據、人工驗收狀態）。避免重複/高成本儲存。
3. **更新引用**：僅在資產真實存在且通過驗收後，將 `src/routes/-mythic-atlas-borrow-star.tsx` 的九幕圖像改指向永久圖像；不可用 CSS 幾何畫代替。保留三語及可訪問性。
4. **自動攔截**：為九幕加 prebuild/CI 資產契約測試：全部九個檔案存在且是可解碼的真實 raster 圖像；有可信尺寸/長寬比及 manifest hash；不得是純 SVG、HTML fallback、空白或低品質佔位。自動測試不能代替藝術品質人工驗收。
5. **發布**：先遵守分支鎖與 PR review、現有 CI、build；合併唯一 `main`，由唯一 Vercel `stone-zhaowu-official` 正式部署，無第二正式站，不做重複消耗配額的部署。
6. **正式驗收**：核對 `release.json` 的 runtime SHA、Production READY、九張 URL 各自 HTTP 200 與正確 `image/webp`/相應影像 MIME、不是 HTML、手機 320/390px、繁簡英三語、九幕畫作內容/順序、無橫向溢出。逐張以實際畫面確認不是幾何 SVG。缺證據一律標記未驗收，不報已上線。
7. **可回退**：保留舊版引用與原畫記錄，以單一 main revert/正式部署回退；不得刪除或覆寫已驗收原圖。
