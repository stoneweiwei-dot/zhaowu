# 昭梧｜五行功能趣味测验 v1.1

状态：ACTIVE IMPLEMENTATION CONTRACT

## 产品定位

该功能属于首页「趣味测验」系列，不是八字排盘，也不判断喜用神。用户不需要出生资料；测验只根据最近 1–3 个月的自报状态，判断当前最值得训练的一项现实功能：

- 木：生长、规划、疏通、方向
- 火：启动、表达、显化、行动
- 土：承载、稳定、落实、完成
- 金：边界、结构、取舍、收敛
- 水：恢复、观察、储备、流动

严禁使用“缺什么补什么”逻辑，严禁把测验结果反推疾病、命局、喜用神、前世或宗教身份。

## 题型与评分

- 12 题单选，每题 5 个选项，选项隐性对应木火土金水。
- 主结果唯一；第一名与第二名只差 1 分时，第二名作为辅轴。
- 平分依次使用 Q4、Q11、Q12、Q1 做 tie-break。
- Q9 为压力过度题：若 Q9 与最终主轴相同，必须提示“要练健康版本，不是继续加码过度形式”。
- 不向用户展示内部数值分数。

## 结果结构

每个结果必须包含：

1. 当前主轴（木/火/土/金/水 + 白话功能名）
2. 为什么现在需要它
3. 3–5 条现实行动建议
4. 两周观察标准
5. 一个过度提醒
6. 接近分数时的辅轴支持
7. 象征性灵光主色/辅色/底色说明
8. 免责声明：不是八字喜用神，灵光颜色不是人体能量检测

免费版本禁止调用任何图片生成 API。未来付费图片功能必须由独立 payment gate 开启，本测验只预留文本语义，不提前生成图。

## 多语言

必须支持 `zh-Hant / zh-Hans / en`。三种语言分别写自然客户文案，不允许英文逐字翻译中文。关键 UI：

- 繁中：你會知道 / 最擅長看
- 简中：你会知道 / 最擅长看
- English: You’ll learn / Best for

英文产品名：`Five-Element Function Test`。
英文主问题：`Which function do you need to strengthen right now?`

## 首页分组说明规则

首页每个分析入口和趣味测验卡都必须直接回答两件事：

- 用户在这里会知道自己的哪一部分。
- 这个体系最擅长看什么。

不得只展示术数名称让客户自己猜用途。

七政四余：自然节奏、反应方式；强项是性情节奏、行动模式、压力反应与天时变化。
前世今生／达摩一掌经：重复习性与熟悉主题；强项是前四世六道、携带习性与重复加强。
紫微斗数：性格底色及关系、事业、财务的运作；强项是人生领域结构和当前十年重点。
内在动物 × 命局瑞兽：当前人格策略与压力反应；强项是行为/决策方式，并在已有命盘时与瑞兽象征交叉。
五行功能测验：当前更需要生长、启动、落地、收敛还是恢复；强项是把近期卡点转成一个现实训练方向。
