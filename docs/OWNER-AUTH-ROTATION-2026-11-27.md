# 站主密碼輪替 · 2026-11-27

1. 由 Stone 本人發起。先確認仍可透過獨立方式管理既有主機與 Supabase 專案。
2. 在本機密碼管理器產生長度介於 32 至 128 的隨機 ASCII 密碼。使用可信任的離線工具從隱藏輸入讀取密碼，計算原字串 UTF-8 的 SHA-256（不加換行），以 64 位十六進位表示。用私密欄位傳遞雜湊，避免終端回顯、指令列參數、聊天、日誌及版本庫。
3. 在既有後端憑證設定中同步替換 Vercel 與驗證站主密碼的 Supabase Edge Functions 的 `ZHAOWU_OWNER_KEY_SHA256`。帳號雜湊、裝置及橋接金鑰各自獨立。安排同一維護時段生效，Vercel 環境變更需經 Stone 批准重新部署。
4. 以新私密視窗確認新密碼可登入並讀取受保護資料。舊密碼及以舊密碼簽發的 session 應失效。加密 cookie 格式更新後，既有密碼登入者須重新登入。
5. Passkey 與裝置 session 獨立於密碼。若輪替原因是裝置遺失，另於站主裝置管理撤銷該裝置，並在快取到期後核對。若新設定失敗，利用保留的主機管理權重新同步兩端雜湊。
6. 密碼登入於同一執行個體對同一來源在 15 分鐘內累計 8 次失敗後回應 429。冷啟動會清空計數，多執行個體間各自計數。
