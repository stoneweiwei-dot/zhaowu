借鑑「先分大類，再放工具」的資訊架構：

- 大類標題先回答使用者在做什麼，例如「生辰排盤／問事起卦／自我探索」。
- 每張工具卡只保留：工具名、短副標、單一主要操作。
- 暖米紙底、深墨字、低飽和強調色；裝飾不與功能搶視線。
- iPhone 390–430 px 優先，不把桌面多欄硬塞進手機。

此項是 UI 語法，不要求照搬來源品牌或現有昭梧首頁架構。

**概念 → 本象／白話 → 生效條件 → 歲運引動 → 現實行動。**

## 4. 神煞使用規則

1. 子平原局主判優先；神煞只作旁證與取象。
2. 必須放回月令、根氣、透藏、格局、病藥、流通、承載、十神戰局與歲運一起看。
3. 同一神煞在不同柱位、組合、合沖刑害與大運流年下，作用可能不同。
4. 不得單憑一顆華蓋、桃花、羊刃、亡神等判人格本質、宗教／通靈、婚姻、疾病、死亡或人生層級。

## 5. 古訓／每日一言的來源標籤

所有格言內容至少分兩類：

- **古籍原文**：只有已確認原典、篇章或可靠文獻來源者才能使用此標籤。
- **今人整理**：網路流傳、現代改寫、來源不明或站主整理語句。

若來源仍待考證，寧可標「今人整理／出處待考」，不可為了文案效果冒充古籍。
