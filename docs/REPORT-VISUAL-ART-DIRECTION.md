# 昭梧｜报告母图美术方向

Version: ZW-REPORT-ART-1.0
Approved: 2026-09-04
Status: P1 report visual system art contract

本文件补充 `docs/REPORT-VISUAL-SYSTEM.md`，锁定 Stone 对母图库的最新审美要求。目标不是把同一人物换背景，而是让每个命理类别拥有独立、可辨认的画面语言。

## 1. 总原则

- 统一风格：旧宣纸宋系图谱、宋系淡彩 / 工笔人物、古画扫描质感、低饱和、低对比、矿物色、纸纤维。
- 统一的是「画种与品牌语言」，不是人物模板。
- 严禁十二月令或其他系列出现：同一张脸、同一站姿、同一构图、同一手持物，只更换季节背景。
- 同一系列至少交替使用：无人山水、远景小人物、半身 / 全身、坐姿、行旅、背影、侧身、俯视 / 平视、室内 / 庭院 / 山水等不同构图。
- 并非每张都要有人物；月令首先表现时令气象，人物只是可选叙事元素。
- 有人物时，手部默认可以自然垂落、负手、扶栏、理袖、行走，不得为了“古风”强行每张都拿树枝、卷轴、扇子、灯、花等道具。
- 同一套图内人物性别气质、年龄感、发式、衣色和距离需适度打散，但保持古典、克制、非商业仙侠。
- 正式网站中文字仍由 HTML/CSS 渲染；母图不依赖 AI 生成准确正文。图中如保留题签，只作为图库源文件识别，网站显示时不得依赖其文字正确性。
- `STONE 原創` 水印由后期或前端统一处理。

## 2. 十天干配色锁定

- 甲木 `jia-wood`：深绿色；参天大木、山林、向上生发。
- 乙木 `yi-wood`：浅绿色；藤萝、柔条、花草、曲直。
- 丙火 `bing-fire`：橘红；日轮、晴光、外放热度。
- 丁火 `ding-fire`：红紫；灯火、夜庭、内照微明。
- 戊土 `wu-earth`：深山土色 / 深棕褐；高山、厚土、城垣。
- 己土 `ji-earth`：浅棕 / 湿润田园土色；沃壤、平畴、水田。
- 庚金 `geng-metal`：浅金；矿石、秋山、坚锐骨架，避免游戏武器海报。
- 辛金 `xin-metal`：珍珠白 / 金白；珠玉、白石、月华、霜露。
- 壬水 `ren-water`：深蓝 / 蓝黑；江河、瀑布、大川、深水。
- 癸水 `gui-water`：浅蓝；雨露、溪泉、薄雾、细水。

这套十天干方向已获批准，后续不要为了“统一”重新洗成同一种米色人物模板。

## 3. 十二月令构图矩阵

十二张必须“同画风、不同镜头”。以下为默认母图方向；可微调，但不得退回同脸同姿模板。

### 寅月 `yin-spring`
- 气象：立春、孟春、初芽、东风、梅柳初动。
- 构图：远景山溪 + 一名行旅者侧身经过，人物占画面不超过 30%。
- 手部：自然行走，不持道具。
- 色调：深绿向新绿过渡。

### 卯月 `mao-spring`
- 气象：惊蛰 / 仲春、细雨、柳烟、花木盛动。
- 构图：**无人山水**；雨中柳岸、燕影、溪桥。
- 色调：浅绿、烟青。

### 辰月 `chen-spring`
- 气象：清明 / 季春、湿土、云开、暮春水气。
- 构图：俯视田陌与山水，人物只作远处小点或完全无人。
- 色调：青灰、湿土米褐。

### 巳月 `si-summer`
- 气象：立夏 / 孟夏、木火渐旺、庭院转暖。
- 构图：园林、水榭、桥影；可有**坐姿人物**倚栏，但不要正中全身站像。
- 手部：扶栏或自然置膝，不拿物件。
- 色调：暖绿、淡朱。

### 午月 `wu-summer`
- 气象：芒种 / 仲夏、日盛、荷塘、水光。
- 构图：大面积荷塘与日光，人物只用背影 / 亭中剪影，景大于人。
- 色调：橘红、暖金、荷绿。

### 未月 `wei-summer`
- 气象：小暑 / 季夏、湿热、田园成熟、土中含水。
- 构图：稻田、沟渠、远村；**不使用主角人物肖像**，可有远处农作小人群。
- 色调：浅土棕、稻金、湿绿。

### 申月 `shen-autumn`
- 气象：立秋 / 孟秋、金气初起、山骨渐显。
- 构图：高远山势、岩石、薄云；可用骑行 / 行旅的远景小人物，禁止中央站像。
- 色调：浅金、岩褐、冷灰。

### 酉月 `you-autumn`
- 气象：白露 / 仲秋、清秋、月华、露气。
- 构图：**无人山水**；月、芦苇、秋水、远亭，强调清澈和留白。
- 色调：珍珠白、淡金、灰米。

### 戌月 `xu-autumn`
- 气象：寒露 / 季秋、燥土、叶落、日斜。
- 构图：黄昏荒坡 / 古道，可出现两名很小的远行人物，禁止单人正面模板。
- 色调：赭黄、深土色、秋褐。

### 亥月 `hai-winter`
- 气象：立冬 / 孟冬、水寒初凝。
- 构图：雪岸、江舟、枯枝；人物仅为舟中或岸边极小剪影。
- 色调：灰蓝、冷米白。

### 子月 `zi-winter`
- 气象：大雪 / 仲冬、水旺、夜深、寒江。
- 构图：**完全无人**；深蓝夜江、月 / 星、雪峰、水面反光。
- 色调：深蓝黑、银灰。

### 丑月 `chou-winter`
- 气象：小寒 / 季冬、寒湿土、闭藏待春。
- 构图：雪后村落、冻田、低山；可有远处牛 / 屋舍烟气，但不要人物主像。
- 色调：灰米、湿土浅褐、冷白。

## 4. 系列去重硬规则

十二月令完成前必须做一次 contact-sheet QA。以下任一情况出现即退回重做：

1. 3 张以上使用几乎相同的人物站位。
2. 3 张以上出现同一类手持物。
3. 3 张以上人物脸型 / 发型 / 衣服轮廓高度相似。
4. 12 张全部有人物。
5. 12 张全部是中央全身像。
6. 只靠色温变化区分月份。
7. 月令主景与对应时节不符。

目标分布建议：

- 4–5 张无人主景；
- 3–4 张远景 / 小人物；
- 2–3 张较明确人物叙事；
- 中央全身站像最多 1–2 张。

## 5. 网站接入顺序

1. 十天干已批准母图：压缩为 WebP / AVIF 后接入 `/public/report-visuals/day-master/`。
2. 十二月令：先按本文件完成去重版，再接入 `/public/report-visuals/month/`；此前继续使用现有 fallback，不得把重复模板批次上正式站。
3. 接入后做 iPhone Safari 390–430 px QA：首图尺寸、lazy load、404 fallback、文字不被图阻塞。
4. 母图只负责意象；排盘、日主、月令、喜忌和实际结论仍以计算层为唯一来源。

## 6. 以后所有新系列默认继承

格局病药、大运流年、前世今生等后续图库也继承同一原则：**统一画风，不统一人物模板；先按命理对象决定场景，再决定是否需要人物。**
