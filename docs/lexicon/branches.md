# 十二地支物象（文案词典）

月令与日支取象。月令仍按节气，不按公历月。

| 支 | 字源／物象 | 昭梧可用的习惯句 |
|---|---|---|
| 子 | 兹，萌动滋生 | 表面上不吵，夜里才重播没说的话 |
| 丑 | 纽，阳气在上未降 | 先吞进肚子，问起来才说没什么 |
| 寅 | 演，开始生长 | 一旦决定动，周围觉得你换了个人 |
| 卯 | 冒，冒土而出 | 外表好说话，心里早有节奏 |
| 辰 | 震，震动成长 | 没说完的话会在心里转好几圈 |
| 巳 | 已，已经长成 | 先看完全局再出手，看太久会烤干自己 |
| 午 | 仵，阴阳交接 | 情绪来得快，人多的地方容易把光打开 |
| 未 | 味，已成有滋味 | 先安顿别人，轮到自己时位置没了 |
| 申 | 身，形体已成 | 脑子比嘴快，拆完才发现对方要被接住 |
| 酉 | 秀，十分成熟 | 看不惯凑合，标准先割伤自己 |
| 戌 | 灭，消灭归土 | 答应过的会守，被食言一次记得特别久 |
| 亥 | 核，成种子收获 | 表面随和，内里只让少数人进来 |
