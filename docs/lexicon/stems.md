# 十天干物象（文案词典）

只帮助把日主写成可被认出的习惯，不单独定吉凶。

| 干 | 字源／物象 | 昭梧可用的习惯句 |
|---|---|---|
| 甲 | 铠甲，万物破甲而出 | 先把骨架撑住，再让别人来靠 |
| 乙 | 草木初生，枝叶柔软屈伸 | 先绕、后占，外人以为软 |
| 丙 | 炳，日光明亮 | 一出现场面就亮，亮完需要暗处 |
| 丁 | 壮，苗壮成长 | 小火慢炖，最怕含糊和潮气 |
| 戊 | 茂，大地草木茂盛 | 立定以后极难被说动 |
| 己 | 起，万物抑屈奋起 | 能把散乱收成可用之地 |
| 庚 | 更，秋天更替 | 一刀切开问题，也容易切开关系 |
| 辛 | 新，秀实新成 | 眼睛先看见瑕疵 |
| 壬 | 妊，阳气潜伏、万物被养育 | 吸收快，没出口就积成雾 |
| 癸 | 揆，萌芽悄然发育 | 雾散之前不交真正的答案 |
