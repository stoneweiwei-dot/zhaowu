# 神煞（点缀表，禁止主判）

课件把神煞写成「带这个就血光／富贵／外遇」。昭梧不采用。

`docs/SPEC.md`：神煞不得凌驾格局。天月二德课件自己也写了——原局不好只是锦上添花。

## 可点缀（一句，不改变判断）

| 神煞 | 最多能说 | 不能说 |
|---|---|---|
| 天乙贵人 | 危时较容易碰到肯伸手的人 | 一定成功幸福 |
| 天德／月德 | 原局的锐角稍被磨圆 | 长寿少病、决定贫富 |
| 文昌 | 学习与表达多一条通道 | 考试必中、名利双收 |
| 太极 | 愿意往里钻 | 一生无大灾 |
| 国印 | 对环境变动较敏感 | 必买房升职 |
| 德秀 | 待人较收得住 | 必得贵人簇拥 |
| 天厨 | 食神／口福的旁证 | 适合开餐厅、吃公家饭 |
| 驿马 | 走动、迁职的象 | 女命不喜、必红杏出墙 |
| 桃花 | 关系张力、被看见 | 时柱＝终见外遇 |

## 禁止写入付费正文

灾煞、劫煞、流霞、飞刃、血刃、羊刃（作主判时）、自缢煞、十恶大败。

尤其禁止：

- 断疾病、手术、流血、车祸、牢狱
- 暗示极端自伤
- 「十恶大败＝一辈子败家」
- 用神煞代替病药与流通

引擎现状：不算神煞。以后若要显示，只能进折叠方法区，且标「点缀，不参与主判」。
