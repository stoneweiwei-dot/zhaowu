# 昭梧紫微斗數高階分析路線 v1.0

狀態：ACTIVE

這份文件鎖定昭梧紫微斗數的高階分析順序。它建立在既有計算真值層與解盤語法之上，不修改星曜安置、四化表、大限方向或其他排盤計算規則。

## 1. 核心原則

紫微報告不得退回「逐宮列星、單星下斷語」的模板。固定採用：

> 資料邊界 → 本命骨架 → 命身宮與三方四正 → 六組對宮軸線／河洛結構 → 生年四化 → 十二宮宮干飛化 → 欽天向心／離心自化 → 來因宮 → 大限宮干四化 → 流年落宮與流年天干四化 → 大限×流年交叉驗證 → 人生主題綜合 → 關鍵時間窗口 → 實務建議 → 研究／娛樂用途聲明。

同一重要結論應盡量由兩個以上相互獨立的層次支持，例如本命＋大限、本命＋流年，或大限＋流年；本命、大限、流年三層重複時才可升級為「高關注窗口」。

## 2. 資料真值分層

每次分析前先區分：

1. `provided`：來源直接提供，例如文墨天機盤面明示的宮位、星曜、生年四化、自化箭頭、來因宮、大限或流年資訊。
2. `deterministic_derivation`：在已鎖定 profile 下可確定推導，例如流年干支、既定十干四化對應。
3. `unavailable`：來源沒有、站內也沒有已驗證規則可推導的資料。

禁止把 unavailable 寫成已知事實。

文墨天機若提示「需專業版才有流月／流日／流時」，而使用者沒有提供那些資料，報告只能停在可用層級。不得自行補造流月、流日、流時星曜或四化。

## 3. 本命骨架

先回答全盤由什麼結構主導，再進入十二宮細節。

必看：

- 命宮與空宮借對宮規則
- 身宮著力點
- 命、財、官、遷三方四正
- 主星組合而非單星拆散
- 輔煞只作過程修飾
- 廟旺利陷只調整功能可用性與成本，不直接等同吉凶

## 4. 六組對宮軸線／河洛結構

十二宮必須同時看六條對宮軸線，觀察互補、張力、鏡像與反覆主題。不得把某一宮完全孤立。

## 5. 生年四化

先看生年祿、權、科、忌落入何宮，再形成全盤資源鏈：

- 祿：什麼正在進入／獲得／黏合
- 權：什麼正在被推動／承擔／控制
- 科：什麼正在被顯化／規範／認可
- 忌：什麼正在形成成本／阻滯／反覆處理

四化不是簡單吉凶分數。

## 6. 十二宮宮干飛化

在已選定且驗證的十干四化 profile 下，逐宮檢查宮干四化飛向何宮，建立宮與宮的作用鏈。

若流派 profile 未鎖定，必須保留差異，不得混用不同表。

## 7. 欽天向心／離心自化

只有以下兩種情況可以啟用：

- 來源盤面明示向心／離心／自化箭頭；或
- 昭梧已選定並驗證相應欽天 profile。

否則標為 unavailable，不得自行補箭頭。

分析時需把自化與生年四化、對宮化入、宮干飛化交叉比對，避免只看到一個箭頭就下結論。

## 8. 來因宮

來源明示來因宮時，將其視為事件／因緣入口之一；再看：

- 本宮星曜
- 宮干飛化
- 對宮
- 三方四正
- 大限／流年是否重複引動

沒有可靠來源或已驗證推導規則時，不得自行指定來因宮。

## 9. 大限

每個大限先定十年主場景，再分析大限宮干四化。

十年分析不能只列十個年份；必須先說清楚這十年的核心命題、資源、壓力、主要轉換方式與風險控制。

## 10. 流年

每一年至少輸出：

- 流年落宮
- 流年天干四化
- 主要事件主題
- 吉凶傾向
- 影響程度
- 注意事項

若使用者要求前八大限、八十流年或完整一百二十流年，逐年均沿用同一字段，不得只寫一句泛泛吉凶。

## 11. 大限 × 流年交叉驗證

優先檢查：

- 限流疊宮
- 本命、大限、流年是否重複引動同一宮
- 同一顆星或同一四化是否跨層重複
- 同一人生主題是否由多宮共同支持

單一流年訊號只能稱為「年度主題／觀察點」，不得直接寫成必然發生的重大事件。

## 12. 人生主題綜合

固定至少整合：

1. 健康
2. 學業／學習
3. 事業
4. 財運
5. 人際／合作
6. 婚姻／感情

各主題必須回扣前面的結構證據，不重新變成單星列表。

健康只作象徵性壓力與照顧提示，不做疾病診斷、手術必然性、死亡或壽夭斷語。

## 13. 關鍵時間窗口

重要年份／區間應標示：

- 時間範圍
- 主要主題
- 吉凶傾向：偏吉／吉中帶壓／中性／偏慎等
- 影響程度：低／中／高／極高
- 為何被升級：例如限流疊宮、跨層重複四化、同一宮被多重引動
- 現實注意事項

「高影響」不是「一定發生」。

## 14. 實務建議

最後把術數語言翻譯成可執行建議，例如：

- 合作權責與合約
- 決策截止條件
- 版本凍結與項目驗收
- 現金流與退出機制
- 工作量與休息節律
- 關係中的共同決策與邊界

建議必須由盤面結構推導，不做泛用雞湯。

## 15. 固定聲明

紫微斗數屬傳統術數與文化性解讀，可用於研究、自我觀察或娛樂。涉及醫療、法律、投資、婚姻等重大現實決策時，不得取代相應專業意見。
