# 七政四餘首頁真值層

狀態：production candidate · `ZW-QZ-TROPICAL-0.1`

## 目的
首頁主分析完成後，直接用同一份出生資料顯示七政四餘，不建立第二套出生表單，也不恢復工具牆。

## 計算分層
- 七政（日、月、水、金、火、木、土）：按出生地民用時間與 IANA 時區換算 UTC，計算回歸黃道地心黃經；五星另外判斷順逆。
- 計都／羅睺：採果老命名口徑「計北羅南」，交點用瞬時修正模型；兩點固定相差 180°。
- 月孛：以月球遠地點派生。
- 紫炁：不是現代天文實體，獨立標成 traditional；採約 28 年一周天的平行模型，不與七政真天象混稱。
- 二十八宿宿度、命身宮、古籍喜忌格：暫不硬塞進首頁真值層。這些會受宿界、盤制與流派政策影響，必須綁定來源與 profile 後再加入。

## UI 邊界
- 只在已有主分析結果後顯示，沿用首頁舊宣紙／宋系閱讀流。
- 390–430px 手機優先；星位圖使用 SVG，不造成橫向溢出。
- 出生時辰未知時不偽造七政盤，只顯示需要精確出生時間的提示；原主報告照常交付。
- 繁中、簡中、英文皆提供直白標籤；英文不要求使用者理解命理術語。

## Regression
`npm run test:engine` 會執行 `scripts/qizheng.test.mjs`，鎖定時區換算、J2000 星位回歸、羅計 180° 對沖、首頁主流程掛載與未知時辰降級。
