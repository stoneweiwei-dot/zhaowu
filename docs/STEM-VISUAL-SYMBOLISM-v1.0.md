# 昭梧十天干命象視覺規範 v1.0

本規範只管理命象／視覺語言，不改八字計算真值。

## 十天干主象

- 甲木：參天古木、棟梁、青山；蒼青／森林深綠。
- 乙木：花木、藤蘿、柔枝；翠綠／玉綠。
- 丙火：太陽、日輪、晴光；朱紅／橙金。
- 丁火：燭燈、燈火、星火；紫紅／暖赤。
- 戊土：高山、城垣、厚土；赭黃／岩褐。
- 己土：田園、沃壤、平疇；茶褐／灰黃。
- 庚金：礦鐵、鋒刃、斧鉞；礦金／鐵灰金。
- 辛金：古法本象保留珠玉、精金；昭梧視覺延伸使用月輪、月華、霜銀；珍珠白／霜銀。
- 壬水：江河、大海、大川；深海藍／Navy。
- 癸水：雨露、溪泉、霧氣；淺水藍／霧青。

## 庚辛與月相

核心口徑：月之清輝偏辛，月之鋒稜可借庚。

- 朔月：藏辛——光藏未露。
- 眉月：初露之辛——纖、秀、清、微。
- 上弦：辛金成形，可兼庚之骨與界線。
- 望月：辛金月華最完整——清輝、圓成、珠玉感。
- 下弦：光勢收斂，庚的切分與收束感漸顯。
- 殘月：辛光退藏，形如月刃，可借庚之鋒稜。

## 絕對邊界

1. 「辛＝月輪／月華」是昭梧的視覺象義延伸；不得冒充古籍原句「辛就是月亮」。
2. 月相只用於圖像、命象敘述與生成提示，不進入日主旺衰、格局、病藥、喜忌、五行比例或任何 deterministic calculation。
3. 不得因出生當天滿月、弦月、殘月而推導辛金旺衰。
4. 庚金仍以礦鐵、鋒刃、剛金為本；弦月／殘月只可借其「刃形」，不把月亮本體改判為庚金。
5. 丙火固定太陽主象；丁火固定燭燈主象，不以「陰火對陽火」硬配丁為月亮。

## 生成原則

天干決定本體，命局決定本體在畫面中的狀態。視覺可依寒暖、燥濕、根氣、透干、流通與已驗證結構調整明暗、環境與物象，但不得讓視覺反向改寫排盤結果。
