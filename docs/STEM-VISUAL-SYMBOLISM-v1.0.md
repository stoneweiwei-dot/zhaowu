## 教學使用順序

1. 先說本象與功能，不先下吉凶。
2. 再回到出生月令、根氣、透藏、格局與制化，確認此象在原局中的真實狀態。
3. 再看大運、流年等時間條件是否引動。
4. 最後才把象義翻成現實中的行動提醒。
5. 圖像、顏色、物象都只能幫助理解，不能取代 deterministic calculation 或 R6.2.1 主判。

## 庚辛與月相

核心口徑：月之清輝偏辛，月之鋒稜可借庚。

- 朔月：藏辛——光藏未露。
- 眉月：初露之辛——纖、秀、清、微。
- 上弦：辛金成形，可兼庚之骨與界線。
- 望月：辛金月華最完整——清輝、圓成、珠玉感。
- 下弦：光勢收斂，庚的切分與收束感漸顯。
- 殘月：辛光退藏，形如月刃，可借庚之鋒稜。

## 絕對邊界

1. 「辛＝月輪／月華」是昭梧的視覺象義延伸；不得冒充古籍原句「辛就是月亮」。
2. 月相只用於圖像、命象敘述與生成提示，不進入日主旺衰、格局、病藥、喜忌、五行比例或任何 deterministic calculation。
3. 不得因出生當天滿月、弦月、殘月而推導辛金旺衰。
4. 庚金仍以礦鐵、鋒刃、剛金為本；弦月／殘月只可借其「刃形」，不把月亮本體改判為庚金。
5. 丙火固定太陽主象；丁火固定燭燈主象，不以「陰火對陽火」硬配丁為月亮。
6. 「甲木就是樹、癸水就是雨」等說法只能作教學比喻；不得把一個物象當成完整十神、格局或事件判定。

## 昭梧視覺方向

- 基底：暖米／淡宣紙，不使用社交媒體式放射白底或卡通爆炸構圖。
- 色彩：礦物青綠、赭石、朱砂、黛藍、霜銀，以低至中飽和度為主。
- 構圖：每張只保留一個中央主象，周圍裝飾退到背景；天干大字、本象小字。
- 線條：細金線、朱印、宋式界畫或工筆線描；避免粗紅框與兒童貼紙感。
- 原創：站主提供的參考截圖只用於理解「具象化教學法」，不得直接再利用原圖、原水印、原角框或原作者版式。
- iPhone：390–430 px 優先，主字與主象先清楚，再增加次級資訊。

## 生成原則

天干決定本體，命局決定本體在畫面中的狀態。視覺可依寒暖、燥濕、根氣、透干、流通與已驗證結構調整明暗、環境與物象，但不得讓視覺反向改寫排盤結果。
