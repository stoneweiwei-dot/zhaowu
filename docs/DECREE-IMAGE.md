# 9:16 命诰图规格 ZW-DECREE-IMG-1.0

来源：Issue #4 GPT 交付。接线：`src/lib/report/decree-image.ts`。

## 原则

1. AI 只生成干净背景图，**不让模型画中文**。
2. 命诰文字、档案编号、`STONE 原創` 水印由前端／后处理叠加。
3. 日主五行只作审美象征，不得写成喜用或吉凶。
4. 不引用紫微、西占、吠陀、奇门等未接入流派符号。

## Base Prompt

见 `buildDecreeImagePrompt()`。

## 叠字层（不要交给图像模型）

| 位置 | 内容 |
|---|---|
| 顶 | `昭梧 · 命诰` |
| 中 | `{reading.decree}` |
| 底 | `命理档案 {result.id}` |
| 水印 | `STONE 原創`，宽约 8%–12%，透明度 25%–50% |

## 五行美术变量（只作色调）

木青绿／火朱砂暖金／土米金山形／金白玉银线／水靛青月白。
