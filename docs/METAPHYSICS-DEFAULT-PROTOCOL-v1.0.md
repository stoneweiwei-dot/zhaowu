# 昭梧命理默认分析协议 v1.0

状态：`CANONICAL_DEFAULT`

适用范围：昭梧网站、报告生成器、站主客户分析、内部 QA、未来接入的 AI / Agent。除非站主在具体任务中明确指定其他方法，本协议为命理分析默认入口。

## 1. 系统权重与职责

- **子平八字：主判。** 负责气如何运行：资料校验、从化真假、月令司令、调候寒暖燥湿、根气透藏、格局体用、病药、流通制化、承载旺衰、十神真假清浊、刑冲合害库、大运流年、现实策略。
- **紫微斗数：独立现象／场景验证层。** 负责事情落在哪个生活场景、以什么方式显现、何时被引动。不得替代八字月令、调候、格局、十神、病药与承载。
- **达摩一掌经：文化／精神象征层。** 只作生命课题、六道与精神象意，不得写成已证实前世历史。
- **风水：空间资料充分时才启用。** 处理真实居住／工作环境，不能用五行数量去机械补命局。

若系统结论不同，必须保留不同观察角度，不得为了统一而硬凑。紫微若反复与现实高度吻合，只能触发对子平主结构的回溯复核，不能自动覆盖八字结论。

## 2. 子平固定分析顺序

资料校验 → 从化真假前置闸门 → 月令司令 → 调候寒暖燥湿 → 根气透藏 → 格局体用 → 病药 → 流通制化 → 承载旺衰 → 十神真假清浊 → 刑冲合害库 → 大运流年 → 现实策略。

禁止：五行计数平均、缺什么补什么、生肖性格、单一日柱定性、神煞凌驾结构、SSS／稀有度／命格等级、无依据的绝对吉凶。

## 3. 紫微七层解释语法

计算通过后，固定依次使用：

1. **命盘计算层**：星曜落宫、命身宫、四化、辅煞、三方四正、大限流年必须先算对。
2. **星曜本质层**：星曜说明“什么功能”。
3. **宫位场景层**：宫位说明“发生在哪里”。
4. **四化变化层**：四化说明“功能如何变化”。
5. **辅煞过程层**：辅曜／煞曜说明“过程是什么性质”。
6. **三方四正结构层**：说明该主题与哪些人生领域互相支持、牵制或反馈。
7. **大限流年时间层**：说明潜在结构何时被放大或触发。

核心句：

> 星曜定功能 → 宫位定场景 → 四化定变化方式 → 辅煞定过程性质 → 三方四正定结构关联 → 大限流年定触发时间。

七层完成后，才进入白话报告。

## 4. 四化统一定义

- **化禄**：输入／获得／黏合。看“什么正在进入”。正常表现为资源、关系、机会、需求较易满足；过度可表现为贪多、依赖、黏住、资源过载。
- **化权**：推动／控制／承担。看“什么正在被推动”。正常表现为决策、执行、主导、责任；过度可表现为控制、争夺、权责压力、强迫推进。
- **化科**：显化／规范／认可。看“什么正在被看见”。正常表现为名誉、资格、表达、解释、被识别；过度可表现为形象负担、评价焦虑、重形式。
- **化忌**：收缩／阻滞／代价。看“什么正在付出代价”。正常表现为问题聚焦、修正、反复处理、成本显现；过度可表现为消耗、执着、延迟、难以脱身。

四化不是吉凶标签，必须改造星曜原本功能，不能覆盖星曜本义。例如天机化权是规划／调度进入更强执行与决策，不等于“当官”；廉贞化忌是边界、欲望、规则、人际复杂度上出现阻力或代价，不等于“必出事”。

## 5. 宫位是场景限定器

同一颗星、同一种四化进入不同宫位，不得输出同一件事。宫位只限定解释范围，不能直接保证具体事件。

- 命：自我定位、行为、主导感。
- 兄弟：手足、同辈、近身协作与资源分配。
- 夫妻：亲密关系、伴侣互动、承诺与权责。
- 子女：子女、作品、创造、下属与延伸成果；必须按问题语境选择。
- 财帛：收入、资源配置、交易与价值交换。
- 疾厄：身体承载、压力出口、生活节奏与恢复；禁止疾病诊断。
- 迁移：外部环境、移动、异地与对外互动。
- 交友：朋友、团队、客户、人脉与合作分工。
- 官禄：职业角色、专业责任、决策与工作方式。
- 田宅：家庭、居住、资产、空间与基础盘。
- 福德：精神节奏、内在需求、恢复与长期满足。
- 父母：长辈、制度、资格、支持与上级关系。

## 6. 三方四正作为关系网络

- 本宫：主场景。
- 三方：资源、结构支持与互相牵动。
- 对宫：外部反馈、张力、互补或镜像。

不得把三方四正做成数值加分。职业能力存在，不代表一定转成收入；必须看财帛等相关场景是否承接。

## 7. 辅曜与煞曜只改变过程性质

- 左辅／右弼：帮助、转圜、协作、支援。
- 文昌／文曲：文字、信息、学习、表达、规范。
- 天魁／天钺：机会、提携、被识别、关键支持。
- 擎羊：直接、尖锐、切割、硬碰。
- 陀罗：拖延、纠缠、反复、慢性消耗。
- 火星：突然、快速、爆发、短时高压。
- 铃星：潜伏、累积、隐性压力、后发。
- 地空：抽空、落差、脱离、预期落空。
- 地劫：损耗、落差、中断、资源流失感。

禁止：火星＝炎症、铃星＝肿瘤、地劫＝车祸、擎羊＝手术等单一医学／灾祸直断。

## 8. 本命＋大限＋流年叠层

- 本命 = 长期结构。
- 大限 = 十年舞台转换。
- 流年 = 当年触发。

采用“基础存在 → 阶段加强 → 年度触发”，不采用 ×1.5、×1.8 等无验证的严重度权重。

重大或高确定性语言至少需要两个独立时间／结构层同时支持；只有单独流年信号时，只能写为观察点或当年触发提示。三层一致可称“重复引动／强化”，仍不得保证外部事件必然发生。

本命星曜与宫位永远不可被大限、流年覆盖；岁运只叠加、激活或改变观察焦点。

## 9. 身体模块固定边界

身体层采用：

固定十二地支人体空间 → 八字寒暖燥湿／病药主结构 → 紫微疾厄宫场景 → 主星功能性质 → 四化状态变化 → 辅煞压力形式 → 岁运触发。

允许输出：
- 哪类身体功能较容易成为压力出口；
- 表现偏急／慢／滞／虚／紧／耗／反复／外力；
- 哪个阶段值得现实检查、休息、调整作息或寻求专业医疗意见。

禁止输出：疾病诊断、癌症／中风／糖尿病等具体断病、必手术、死亡寿夭、停药、替代医疗建议。

若出生时辰不可靠，紫微身体层直接【不作判定】。

## 10. 知识来源五级

每条内部规则或解释必须属于以下之一：

1. `CALC_TRUTH`：可重现、可测试的计算真值；例如安星、落宫、四化、岁运计算。
2. `CLASSICAL_INTERPRETATION`：可追溯传统文本的解释。
3. `MODERN_INTERPRETATION`：近现代流派整理或明确标注来源的现代转译。
4. `OWNER_MATERIAL`：站主提供的教学／实战／整理素材；可吸收，但不得冒充古籍真值。
5. `QUARANTINE`：疾病诊断、死亡灾祸直断、未验证数值权重、单一星曜直接推出重大事件等；保留作审计，不得进入客户结论。

计算真值与解释层永远分库／分字段，不能因为一段解释“看起来很准”就反向修改排盘算法。

## 11. 冲突处理

- **计算规则冲突**：保留 profile / version / provenance；不得静默合并。
- **解释规则冲突**：保留不同来源观点，降级确定性，说明差异。
- **紫微与八字冲突**：八字主结构继续主判；紫微放在【两套系统观察角度不同】。
- **现实反馈与系统冲突**：先校时、校输入、校计算 profile，再回溯解释；不得为求吻合无限圆解释。

## 12. 证据与语言等级

内部可使用：
- `observation`：单一层／单一信号，只作观察。
- `supported`：至少两层独立结构一致，可使用【较高概率】或“较明显”。
- `reinforced`：本命、大限、流年三层一致，可使用“重复引动／强化”，但仍不可写“必然发生”。

禁止把内部 evidence count 转成命好命坏、吉凶百分比、疾病严重度或 SSS 等级。

## 13. 算力与性能策略

1. **确定性计算先做，而且只做一次。** 排盘、四化、宫位关系、三方四正、大限流年全部由 TypeScript deterministic engine 计算，不调用 AI 重算。
2. **缓存 engine snapshot。** 同一份报告的九页／十页共享同一个 `engine_snapshot` 与 `evidence_trace`，禁止每页重复排盘。
3. **AI 只做综合与语言转译。** 若启用 AI，只传结构化事实、来源标签与解释语法；不得要求模型重新计算干支或紫微落星。
4. **免费层优先零 AI／低算力。** 可由确定性模板直接给核心答案与简明解释。
5. **付费层才增加综合推理。** AI 负责跨页面一致性、白话、客户问题映射与长文本压缩；仍不能覆盖计算真值。
6. **图像与文本分离。** 图片失败不影响文字报告交付。
7. **Fail-open text。** AI 增强或图片失败时，必须回退到确定性文字结果，不让页面卡死。
8. **证据先于文案。** 每个关键结论先产生内部 evidence trace，再允许生成客户文案。
9. **不为“更多流派”浪费算力。** 只有资料充足且该系统能回答当前问题时才启用，不做无关系统全盘计算。

## 14. 默认路由

所有命理问题默认先启用子平协议。

紫微仅在：出生时辰可靠 + 历法输入完成标准化 + calculation profile 可用时进入现象验证。达摩一掌经仅在数据完整时作为象征层。风水仅在有真实空间资料时启用。

对客户输出时：先直接回答问题，再给依据、条件、风险边界和行动建议；不以术语堆叠替代答案。

## 15. 网站紫微报告输出固定结构

紫微报告必须按：

【本命长期主题】 → 【宫位场景】 → 【四化如何改变星曜功能】 → 【辅煞过程性质】 → 【三方四正牵动】 → 【大限放大】 → 【流年触发】 → 【白话现实表现】 → 【行动／验证点】。

跨系统报告另分：

- 【与八字一致】
- 【紫微补充的新信息】
- 【两套系统观察角度不同】

## 16. 默认生效规则

除非站主明确说“这次不要用默认命理协议”或指定其他研究模式，所有后续命理分析、客户报告、网站报告与内部 AI 提示词都以本文件为默认规范。具体新指令只覆盖发生冲突的局部，不自动删除本协议其他安全与计算边界。
