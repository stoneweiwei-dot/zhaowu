# 昭梧｜站主素材入庫：地支求財環境取象＋生活五行取象

適用：昭梧八字分析、生活環境建議、財路／發展地點問題的低權重旁證。

不適用：排盤計算真值、用神主判、單獨決定求財地點、以「缺什麼補什麼」作命理結論。

## 1. 月支三組與求財環境取象

此規則只作民俗速查／環境取象，不作子平主判。

- 寅、申、巳、亥：四生／四長生。取動、遷移、奔走、開拓之象。可作「外地、跨區、流動型發展」的旁證。
- 子、午、卯、酉：四正／四旺。取旺地、正位、資源與人氣集中之象。可作「大城市、核心市場、高密度資源場域」的旁證。
- 辰、戌、丑、未：四墓／四庫。取收藏、承載、積累、固定根基之象。可作「本地扎根、穩定經營、基地型發展」的旁證。

### 硬性限制

1. 禁止寫成「月支是哪一組，就一定去哪裡求財」。
2. 「四正＝大城市」「四庫＝本地」屬現代生活化延伸，不視為古法定律。
3. 正式判財路／發展地點，仍依昭梧固定主序：資料校驗 → 月令／調候 → 根氣透藏與有路 → 格局體用 → 病藥 → 流通制化 → 承載旺衰 → 財星與十神戰局 → 刑沖合害墓庫 → 大運／流年／LBX；並綜合驛馬及實際環境條件。
4. 月支三分法只能增加或降低某種環境選項的旁證權重，不得推翻完整命局結論。
5. 對外若展示此速查，必須附註：「僅供環境取象，不作求財地點主判；實際以完整命局與大運為準。」

## 2. 生活五行取象

生活物件、寵物、植物只作象意與環境建議，不得等同「補進八字某個五行」。

- 貓：可取寅木之象；屬生活象意，不等於養貓即可補木或改命。
- 狗：主取戌土之象。戌兼火庫並可參與寅午戌火局，但不得因此直接寫「狗屬火」。
- 魚／水族環境：可取水象。
- 龜：可依玄武／北方傳統象意取水象，但只作象徵旁證。
- 活植物：本體優先取木。多肉、蘭花等仍先按植物之木理解；土培、陶盆、石材等可另取土象。
- 金桔：不可因名稱有「金」便直接判金；植物本體仍先取木。若使用白色、金屬、圓形等，另作金象環境元素討論。

### 硬性限制

1. 禁止「八字缺什麼就補什麼」。
2. 禁止以五行數量少、沒有透出、生肖、顏色、寵物或單一物件直接定喜忌／用神。
3. 生活取象必須服從完整命局的調候、格局病藥、流通、承載與實際喜忌。
4. 任何寵物建議優先考慮照護責任、居住條件、成本與動物福利，不得為「補五行」而鼓勵不合適的飼養。
