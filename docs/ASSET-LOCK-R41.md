# R41 owner-original asset lock

This release uses the owner-provided original assets without generating a replacement artwork set.

- Home-screen/app logo: owner-provided gold lotus + cinnabar dot original image.
- Intro/loading: owner-provided twin-lotus blooming clip (twin buds → bloom → gold light), using the ~1.1 MB web-optimized copy only as a loss-minimizing delivery encoding of the same source clip.
- Intro structure, timing/fallback behavior, and accessibility remain unchanged except for asset references.
- Home-screen icon URLs are fixed and unversioned so normal deployments do not require users to delete/re-add the iPhone Home Screen shortcut.

Do not substitute the single-lotus generated clip, indoor flame clip, rain-camera clip, geometric lotus, or versioned icon URLs.
