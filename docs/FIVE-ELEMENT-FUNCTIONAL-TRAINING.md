# 昭梧｜五行功能訓練＋象徵靈光圖譜（ZW-FIVE-ELEMENT-FUNCTION-1.0）

狀態：`ACTIVE DERIVED REPORT MODULE`

本模組只消費既有八字結構化結果，不修改排盤、月令、旺衰、格局、病藥、刑沖合害或大運計算核心。

## 1. 目的

把五行從「缺什麼補什麼」改成現實功能訓練：

- 木：生發、規劃、條達、成長、疏通
- 火：啟動、表達、顯化、溫度、影響力
- 土：承載、穩定、落地、轉化、完成
- 金：結構、取捨、邊界、收斂、標準
- 水：儲備、觀察、流動、恢復、深思

任何建議都必須先讀既有結構證據；不得因某一五行數量少、百分比低、顏色偏好或表面缺失就直接判定要補。

## 2. 六態 Gate

系統保留六種功能狀態：

1. `beneficial_but_insufficient`：有利但不足，可適量訓練。
2. `beneficial_but_blocked`：有利但受阻，先清阻力再訓練。
3. `already_sufficient`：已足夠，只維持，不再加碼。
4. `overactive`：過度，不再增強，以疏導／泄化／制衡為主。
5. `apparently_missing_but_not_to_add`：表面少，但不宜增加。
6. `needs_mother_qi_or_bridging`：先建母氣、承接或通關條件。

只有前兩態允許「主動增強功能」。其餘狀態不得用「補元素」包裝。

如果上游結構證據不足，必須 fail closed：不指定主訓練元素，不虛構喜用神。

## 3. 免費報告

免費／一般報告只顯示文字：

- 目前功能主題
- 為什麼是現在
- 現實可執行的訓練／調節方式
- 一至四週觀察指標
- 過度提醒
- 象徵靈光主色／輔色／脈輪主題

前台不得呼叫任何圖片生成 API。內部結構證據與 prompt 不直接展示給客戶。

## 4. 靈光／脈輪邊界

靈光與七脈輪只作象徵性人格與人生主題圖譜，不是：

- 醫學檢查
- 人體能量測量
- 客觀脈輪診斷
- 宗教等級
- 前世／六道身份證明
- Starseed／星際種族／高維身份判定

禁止偽百分比，例如「紫色 35%」。只使用主色、輔色、點綴色、保護底色等非測量式層級。

## 5. 付費視覺 Blueprint

系統可以提前建立兩個內部 9:16 prompt blueprint：

1. 五行功能訓練／調節圖
2. 個人象徵靈光／脈輪圖譜

Prompt 可以在未付款狀態先準備，但圖片生成旗標必須保持關閉。真正準備 provider job 前必須再次驗證：

`paymentStatus === "paid" && tier in ["paid_basic", "paid_full"]`

即使使用者屬於「過度／不宜增加／先通關」狀態，付費圖也只能視覺化調節、泄化、維持或支持條件，不能偷偷改寫成直接增強元素。

目前版本只建立與驗證 Blueprint／job gate；沒有在免費前台接入圖片 provider。

## 6. 視覺規格

付費視覺統一：

- 9:16 手機直式
- 舊宣紙／宋系圖譜 × 現代高端資訊圖
- 東方礦物淡彩、清楚層級
- 禁止高飽和塑膠 CG、廉價兒童教材、遊戲角色卡 UI
- 圖像模型不負責生成可讀中文字或水印
- `STONE 原創` 由產品後處理層疊加

## 7. 驗收

至少驗證：

- 六態都有明確 action gate。
- provisional 不會升格成確定喜用神。
- 不使用五行百分比決定補法。
- 免費／not_required 狀態無法準備圖片生成 job。
- 只有明確 paid tier + paid 狀態能準備兩個 9:16 job。
- support-first 狀態的圖像 prompt 明確禁止直接增強。
- 靈光輸出無醫療、能量檢測、宗教身份或偽百分比聲稱。
- 三語前台不顯示內部 evidence／prompt。
