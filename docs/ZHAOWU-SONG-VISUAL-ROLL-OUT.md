## 2. 驗收基準

每一批都必須同時符合：

1. 一套宋式編輯骨架；不用卡牆、巨型膠囊、玻璃浮層或厚重陰影。
2. 單一礦物山水背景可見；文字落在暖紙閱讀面，正文保持深墨色。
3. 主要圓角 6–12px、1px 細線、低陰影；朱砂只作必要動作，金色只作節點。
4. 中文標題用宋體序列，英文用 Iowan／Baskerville／Georgia；長文寬度與行距適合閱讀。
5. 390px 寬度無橫向溢出；操作目標至少 44px；日／夜模式都可讀。
6. 不改功能、資料、計算、權限、付款、路由與多語行為。
