# 昭梧｜免費十干十二支圖鑑（2026-11-02）

## 新授權與既有報告關係

站主要求將本次對話創作的十天干 + 十二地支 9:16 男女雙人圖鑑放入免費報告；不另建立第二個報告或付費入口。對「基本盤免費，盤後深批收費」的舊設計，只調整文化圖鑑的免費界線，付費格局、流年、詳細判斷保留。原有 DayStemPortrait/BranchScenery/ReportVisualBook 不刪除，避免其他路徑中斷。

## 已實作的文字與選圖程式

- `src/lib/report/free-stem-branch-atlas.ts`：十干十二支共 22 條，三種受支援語系繁體／簡體／English 的分離文字資料；`selectFreeAtlas` 只讀已計算的 `chart.dayMaster` 與有效 `chart.pillars`，日干一位，地支按柱去重至多四位。
- `chart.gender` 一律沿用使用者表單的 `male / female / unspecified`；不依生肖、插畫人臉、伴侶偏好猜性別。未選擇性別使用中性文本；不額外更動大運順逆或十神計算。這套圖本身男女同框，因此不聲稱有分男女兩張圖。
- `src/components/free-stem-branch-atlas.tsx`：對所有權限層（含未付費）開放；AnalysisForm 四柱預覽與 ResultView 直接引用，不修改既有付款驗證。
- 英文／簡中站內正文以實際翻譯字串呈現，**不得**把繁體中文烙字海報當作三語素材，或以瀏覽器自動文字轉碼宣稱完成圖片翻譯；原始圖若展示，另標明文字語系。
