# 昭梧｜宋式主體審美框架

狀態：`ACTIVE VISUAL AUTHORITY`

適用範圍：昭梧公開首頁、今日指引、生辰輸入、命盤、問答、完整報告、登入與站主工作面。功能與資料契約不因本框架改動。

## 核心定義

> 宋式不是貧乏的簡，而是極致豐盛後的收斂。昭梧不靠堆滿元素製造高級感，也不把留白做成空洞寡淡；每一筆色、線、景與文字都必須有層級與用途。

## 八條執行規則

1. **一套骨架**：全站只保留「宋式編輯排版」作主體視覺。漫畫、命誥圖、圖庫素材與動畫都是內容層，不得另起一套品牌母版。
2. **留白有節奏**：留白用來分組、停頓與聚焦，不用來撐高頁面。手機首屏先看見品牌、當前入口或核心操作，禁止巨大空英雄區。
3. **一窗之景**：首頁只用一層可辨識的宋式遠山／礦物青綠背景；山石墨線、遠近與空氣感應看得見，但低於不透明暖紙閱讀面。
4. **一紙承文**：生辰、命盤、問題與報告使用連續暖紙閱讀面。避免大膠囊、卡片牆、玻璃擬態與層層浮框。
5. **一套色序**：暖米紙為底，深松綠建立主層級，礦物金只作細線與次級提示，朱砂只作少量關鍵標記。日間禁止大面積深綠壓住正文。
6. **線重於影**：以 1px 細線、6–12px 低圓角和極弱紙面陰影分層。陰影只表達紙張深度，不製造懸浮 App 卡片感。
7. **字先於飾**：中文標題用宋體系，英文標題用 Iowan Old Style／Baskerville／Georgia；正文以手機可讀為準。裝飾不能迫使正文縮小、溢出或橫向拖動。
8. **日夜同構**：夜間是墨色環境＋暖紙正文；暖紙仍用深墨字，只有真正的暗色承載面才用月白字。不得全域把所有文字洗成亮色。

## 紙墨細節與手機尺度

- 日間閱讀面以宣紙 `#F7F3EA`、主墨 `#1F1F1C`、正文墨 `#4A4A44` 為參考；天青 `#9DB8B0` 只作選中細線，竹青、茶褐、朱砂只作少量點睛。現有深松綠仍可作夜間承載面，不能用日間墨色覆蓋其文字。
- 今日指引用單一紙面與 1px 淡線串接頁籤、穿衣、黃曆與靈籤；選中狀態只需細線與文字對比，無須填色塊。靈籤維持可辨識的紙面對話框與遮罩，關閉與鍵盤操作要清楚。
- 標題用宋體，正文先求 iPhone 可讀；導覽與輔助文字不機械縮到 12px，主要點擊區至少 44px。手機內距按實際可用寬度設定，不能硬套桌面 40px 內距或 120–200px 空段。
- 動效以透明度與輕微位移為限，尊重 `prefers-reduced-motion`；互動回饋不統一延至 0.8 秒，以免按鈕顯得遲鈍。
- 青玉小龍保持唯一助手與播放器入口；命書預設以連續文字閱讀。漫畫 Lite 仍可切換閱讀同一份內容，六段以細線串接，完整文字仍可展開。

## 禁止項

- 黑底小字、低對比灰字、整頁暗綠色塊。
- 大圓角卡片牆、膠囊堆疊、厚重陰影、玻璃擬態。
- 為了「古風」堆印章、雲紋、金粉、發光、霧化或廉價玄學符號。
- 把留白理解成刪空內容，或把背景淡化到肉眼不可見。
- 新增 `final-final` 樣式表、runtime DOM 注入或第二套正式站母版。

## 現行落點

- 最後視覺權威：`src/zhaowu-design-system.css`。
- 手機閱讀寬度：最大 560px；iPhone 優先，無橫向溢出。
- 首頁 Hero：縮短無效空白，以宋體、細線和短句建立節奏。
- 今日指引：日間回到暖紙閱讀面；夜間才使用深松綠承載面，兩者各自保持足夠對比。
- 核心閱讀面：低圓角暖紙、薄邊、弱陰影；報告保持一份連續閱讀層。
- 背景：沿用單一 `/wallpaper-song.jpg`，不新增第二張背景或外部運行依賴。

## 驗收

- 390px 與 430px 寬度無橫向溢出，主要操作可直接觸及。
- 日間／夜間的標題、正文、次要文字與按鈕均可讀。
- 遠山可辨識，暖紙正文不透底、不被背景干擾。
- 首頁、登入、生辰、報告原有流程與資料不因視覺改動受影響。
- 圖片或背景失效時，文字與核心操作仍正常交付。
