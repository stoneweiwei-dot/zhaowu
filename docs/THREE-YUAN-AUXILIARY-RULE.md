# 胎元／命宮／身宮輔助規則 v1.0

狀態：`AUXILIARY_RULE`

適用範圍：昭梧八字分析、報告生成、QA 與後續 Agent。此文件是 `STONE R6.2.1` 之下的低權重補證規則，不改寫現行子平主判順序。

## 1. 核心定位

胎元、命宮、身宮不能視為三個與四柱同等可靠、同等重要的「額外柱」。昭梧仍以年、月、日、時四柱作唯一子平主判；三者只在四柱本局已完成後作一致性檢查與補充象義。

權重固定為：

- 四柱本局：最高；
- 胎元：中低；
- 命宮：低至中；
- 身宮：低。

禁止把四柱加胎元、命宮、身宮合成「七柱」後重新計算旺衰、格局或用神。

## 2. 胎元

標準計算法固定採通行月柱推算法：

- 胎元天干 = 月干下一位；
- 胎元地支 = 月支向前第三位。

例如：`辛酉月 → 壬子胎元`。

此算法的意義是建立固定、可重複、可比較的術數模型，不代表能還原生物學受精日期。出生前三百日法、胎息、受氣日屬不同模型，不能與胎元混稱。

胎元不得納入五行票數或日主旺衰計算，因為胎元本身就是由月柱機械推導，再計一次會造成月柱資訊二次加權。

胎元只檢查：

1. 是否重複原局已存在的喜忌或結構訊號；
2. 是否與年、月柱形成明顯刑沖合害；
3. 是否與早年、父母、根基、體質等已由原局成立的議題呼應；
4. 是否在相關大運、流年再次被引動。

只有原局已有訊號而胎元再次同向時，才允許提高旁證信心。

## 3. 命宮

主口徑採《三命通會》式農曆月法：

1. 正月安子，二月安亥，三月安戌，依次逆行至十二月安丑；
2. 在出生月所在宮位放入出生時辰；
3. 時辰順排，直到卯時；
4. 卯時落到的宮位即命宮地支；
5. 命宮天干再按出生年干以五虎遁推出。

經典校驗例：`甲子年三月戌時 → 丁卯命宮`。

昭梧同時計算節令月敏感度版本。若農曆月法與節令月法得到不同結果，或遇閏月等月界爭議，命宮自動降級為低可信度，兩個結果都保留，不強行選一個當真值。

命宮保留「星命座標」性質，主要觀察與原局、三方、流年星煞及既有喜忌訊號的呼應。命宮不得直接加入日主旺衰，也不得因命宮一柱更換用神。

## 4. 身宮

古典核心採「逢酉安身」：

1. 子位起正月，順排至出生月；
2. 在出生月落宮放入出生時辰；
3. 時辰順排、宮位逆行，直到酉時；
4. 酉時落到的宮位即身宮地支。

校驗例：`甲辰月、三月、丑時 → 身宮午`。

古籍較清楚的是身宮的宮位地支。若網站顯示完整身宮干支，昭梧固定採「由月柱干支同步順推到身宮支」的後世研究口徑，並必須標明它不是所有古法共同承認的完整柱。

例如：`甲辰月、三月、丑時 → 午宮；依固定後世口徑為丙午`。

身宮只用於補充「同一原局傾向如何落到行動、承擔、執行與身體承載」，不得單獨斷財富、疾病、婚姻、壽夭或重大吉凶。

## 5. 未知時辰與衝突處理

- 時辰未知：胎元可計算；命宮、身宮固定標示 `不作判定`；
- 真太陽時校正跨時辰邊界：沿用昭梧既有出生時辰候選驗證流程；
- 農曆月命宮與節令月命宮不同：標記低可信度；
- 閏月：命宮可信度降級；
- 三垣與四柱主判衝突：保留衝突並降級三垣，不改寫四柱主結論。

## 6. Runtime 硬限制

胎元、命宮、身宮：

- 不參與五行數量；
- 不參與日主旺衰；
- 不參與格局票選；
- 不直接決定用神；
- 不取代月令、調候、病藥、流通與承載；
- 不在資料不足時補成確定結論；
- 不把術數胎元宣稱為實際受精日期；
- 不把單一沖合、納音或十神寫成必然事件。

## 7. 證據與驗證

目前沒有可靠受控研究證明「四柱 + 胎元 + 命宮 + 身宮」穩定比標準四柱更準。因此昭梧不把三垣的加入描述成準確率提升，只把它視為可記錄、可回測的輔助層。

建議內部驗證採雙模型：

- 模型 A：只用四柱與大運；
- 模型 B：四柱與大運完成後，再加入胎元、命宮、身宮。

預先寫下可驗證事件，再比較模型 B 是否真的減少錯誤，而不是只增加敘事。

## 8. 最終一句

胎元可留，命宮可參，身宮慎用；三者只能補證，不能奪權。四柱看不清，加入三垣通常只會更亂；四柱已看清，三垣最多補細節，不應改變主結論。
