# 昭梧收费版报告｜视觉叙事规范

版本：ZW-PAID-REPORT-VISUAL-1.0  
状态：商业母版规范；只约束收费版的叙事结构、视觉映射与成品呈现。  
优先级：低于 `docs/SPEC.md` 与 `docs/CONTRACT.md`。若本文件与子平主判、排盘、权限或技术契约冲突，以前两者为准。

## 0. 来源与使用边界

本规范参考《雲潭八字訂製繪畫_昭梧_》的“命理信息 → 四柱分层叙事 → 单柱意象 → 最终合成订制画”的产品方法，但不得复制其具体画面、固定标签、文案、映射表、作品命名或版权元素。

原参考的关键结构：
- 日柱被定义为“性格和喜好”的视觉主体。
- 月柱被定义为“周围环境和所担任的角色”。
- 年柱被定义为“世界观和处世之道”。
- 时柱被定义为“对未来的期盼和人生信念”。
- 最终把四柱象征组合成一幅有专属名称的订制绘画。

上述结构只作为视觉叙事层。命理结论必须先由昭梧子平核心得出，再允许进入视觉转译。

## 1. 总原则

收费版必须做到：

`命局证据 → 所起作用 → 人生表现 → 视觉象征 → 最终合成画`

任何视觉元素都必须能反查到前面的命局证据，不允许为了“好看”先决定龙、狐、宫殿、法器，再反向编命理理由。

文字报告即使绘画失败，也必须独立完整；绘画是收费版的最终合成资产，不是用来遮盖判断不足的装饰。

## 2. 命理主判不可被视觉层覆盖

视觉叙事不得改变：
- 子平八字唯一主判。
- 月令、旺衰、调候、格局、体用、病药、流通、刑冲合害与岁运的判断优先级。
- `usefulProvisional=true` 时，不得从粗候选派生确定的颜色、方位、时段、宠物、摆设或职业吉凶。
- 禁止用五行数量或百分比作为主判。
- 禁止“缺什么补什么”“合必化”“冲必凶”。

视觉层只能“翻译已经成立的判断”，不能生成新的命理结论。

## 3. 四柱视觉叙事框架

### 3.1 日柱：核心主体

角色：最终画面的主要生命体或核心存在。  
用途：承载日主、本体气质、日支内在驱动，以及命局最稳定的主体特征。

允许输出：
- 核心瑞兽 / 人形 / 灵体 / 器物主体。
- 主体姿态、眼神、运动方向、材质、尺度。
- 一句“力量面”与一句“失衡面”。

禁止：
- 只凭日干固定人格模板。
- 只凭日支直接断性格或命运。

### 3.2 月柱：环境与角色场

角色：主体所处的主要空间、秩序、社会角色与生存方式。  
用途：承载月令、季节气候、格局环境、职业/社会角色的可视化。

允许输出：
- 宫、庵、台、城、山门、水域、庭院、工坊、殿宇等“场域”。
- 场域的秩序感、开放/封闭、繁复/简净、冷暖、密度。

禁止：
- 把月柱固定等同某种职业。
- 只因十神名称就直接写“教师/官员/艺术家”等确定职业。

### 3.3 年柱：天幕与世界观

角色：最终画面的时代气候、远景、天象、社会背景与外部世界。  
用途：承载年柱在全局中的外在背景作用，不作为独立宿命结论。

允许输出：
- 天光、云层、霞、雨、霜、星宿、山河远景、城市轮廓。
- 外部世界给主体带来的压力、机会、边界或扩张感。

禁止：
- 把年柱直接定义成固定“时代使命”。
- 使用“被选中”“注定凌驾”“天命统治”等确定性玄化措辞。

### 3.4 时柱：未来方向与工具

角色：主体面对未来时的动作、工具、法器、路径、出口与目标方向。  
用途：承载时柱、大运/流年方向、未来习惯与行动机制的视觉表达。

允许输出：
- 法器、罗盘、灯、杖、珠、卷轴、舟、门、桥、星图等。
- 主体朝向、路径、远方目标、开合关系。

禁止：
- 仅凭时柱直接断“命中注定成为某类人”。
- 未完成岁运作用链时，把未来画面写成确定事件预言。

## 4. 最终单张合成图

最终收费版应优先生成“一张可收藏的最终成像图”，而不是四张互不相干的插画。

合成顺序：
1. 天地景象：月令、寒暖燥湿、流通、刑冲合害、承载关系。
2. 核心主体：由日主/日支与全局主轴决定。
3. 环境场：由月柱与主要结构决定。
4. 天幕远景：由年柱承担。
5. 行动工具与方向：由时柱、岁运窗口承担。
6. 感应护法/法器层：仅作为象征性辅助，不得冒充客观宗教事实。

最终图必须有专属作品名，命名格式建议：

`{核心天地意象} · {主体/法器/动作}`

例如格式而非固定内容：
- 雾海玄庭 · 持星图的青龙
- 金阙秋水 · 负灯而行的玄狐

作品名必须从本人的命局证据生成，不得从固定词库随机拼接。

## 5. 收费版页面节奏

建议 9–15 页，不要求死守原参考页数。

推荐节奏：
1. 封面：作品名 + 最终画。
2. 命盘校验：出生资料、四柱、真太阳时/子时规则、校验状态。
3. 核心结论：先说人话，不先堆术语。
4. 日柱视觉主体页。
5. 日柱证据解释页。
6. 月柱环境页。
7. 月柱证据解释页。
8. 年柱世界观页。
9. 年柱证据解释页。
10. 时柱未来方向页。
11. 时柱证据解释页。
12. 合局关系：把四柱拉回整体，禁止四柱割裂。
13. 岁运触发：只写有依据的时间窗口。
14. 最终合成图 + 作品命名解释。
15. 结尾：最高优先行动 + 边界说明。

页面可根据内容减少，但不得出现“为了凑页数而重复同一句命理结论”。

## 6. 视觉语言

默认气质：东方高级、克制、收藏册感，不做廉价“算命海报”。

建议：
- 米白 / 宣纸 / 绢本质感底色。
- 大量留白。
- 低饱和主色 + 少量高纯度五行色作强调。
- 标题大、正文小而疏，层级清楚。
- 主视觉页与解释页交替，避免每页都塞满字。
- 四柱/十神/干支小标识可作为边角索引，不抢主视觉。

不得直接复制参考 PDF 的具体配色、构图、图标、龙形、版式比例或版权标识。

## 7. 文案语气

收费版不是哄人，也不是神谕。

必须：
- 先给判断，再给依据。
- 同时写力量面与失衡面。
- 把抽象命理转成人能理解的生活表现。
- 用“倾向、容易、在某条件下、当岁运触发时”等强度词控制确定性。

禁止：
- “被选中的生命”。
- “命中注定成为引路人”。
- “一定成功/一定结婚/一定破财”。
- “宇宙指定你……”等无证据玄化。

## 8. 原参考中不得照搬的固定映射

以下只能作为“参考作品采用过的艺术手法”，不能进入昭梧算法：
- 天干固定人格词。
- 地支固定能力词。
- 十神固定成“分享/传播/制造/革新/构想/扩大/维持/守护/教导/研究”。
- 天干固定天象。
- 地支固定未来类型。
- 五行固定工具职业类型。

昭梧必须先经过整局结构，再决定是否采用类似视觉词汇。

## 9. 数据校验门槛

收费版在进入视觉生成前必须完成：
- 公历出生日期与四柱一致性校验。
- 月令校验。
- 出生城市/时区校验。
- 真太阳时状态明确。
- 子时换日策略明确。
- 缺时辰时，禁止伪造时柱视觉层；时柱相关画面需标“未定”或降级为中性远景。

任何基础资料冲突必须先拦截，不允许像参考示例那样出现“年份文字与年柱不一致”仍继续输出完整收费报告。

## 10. 原创与版权

昭梧只学习“信息分层与视觉叙事方法”，不复制参考作品表达。

禁止：
- 复刻参考 PDF 的具体图像。
- 复刻其固定物象组合。
- 复刻其固定标题格式、版权元素或作者标识。
- 把参考的 50 万种组合映射表转录成昭梧数据库。

昭梧应建立自己的：
- 瑞兽映射。
- 天地景象词库。
- 护法/法器象征库。
- 画面构图规则。
- 作品命名规则。

## 11. 生成失败与降级

文字与图像必须解耦。

若图像服务失败：
- 文字收费报告照常完成。
- 返回“最终成像描述 + 作品名 + 视觉元素清单”。
- 不阻塞首屏直答或文字报告。

不得因图片失败导致整份报告白屏、超时或消失。

## 12. 验收清单

收费版上线前至少检查：
- [ ] 所有主要结论可追溯到命局证据。
- [ ] 日/月/年/时四层有整体回收，不是四个独立人格测试。
- [ ] 最终合成图包含主体、环境、天幕、未来工具/方向。
- [ ] 不含“缺什么补什么”或五行百分比主判。
- [ ] 未完成正式喜用时，不输出确定幸运色/方位/时段。
- [ ] 不使用“被选中/注定使命”等确定性玄化句。
- [ ] 出生日期、四柱、月令、时区校验一致。
- [ ] 缺时辰时不伪造时柱。
- [ ] 画面生成失败时文字报告仍完整。
- [ ] 成品视觉与参考 PDF 保持原创差异。

## 13. 产品定位一句话

昭梧收费版不是“把八字画成漂亮图片”，而是：

> 先以子平完成判断，再把已经成立的命局结构转译成一幅一人一局、可解释、可追溯、可收藏的东方视觉作品。
