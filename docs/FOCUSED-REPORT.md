# 昭梧｜统一完整报告（ZW-FOCUSED-REPORT-2.1）

> 本文件取代旧的固定九页以及 2026-08-24 的四核心区结构。新报告不得恢复 01、02、03… 的多 session 排列。

## 1. 产品结构

客户完整报告固定只保留两个内容块：

1. **总体概括** — 把直接结论、与本题有关的命理依据、时间节奏、现实行动，以及确实相关的关系条件合并成一份连续总结。不得为了篇幅再拆成「直接结论／命理依据／时间与节奏／现实行动」等独立 session。总体概括末尾可以加入最多两条与本题匹配的「命理建议／修心提醒」，但必须继续留在同一个 summary 内，不新增第三个 session。
2. **身体需要注意** — 在总体概括之后单独出现，用十二地支身体象义系统给出身体观察重点。

旧记录里的 `conclusion / basis / timing / action / relationship` 只作为历史兼容键；新生成报告只写 `summary / body`。

## 2. 命理建议／修心提醒

命理建议来自站主维护的修心内容库，定位是把命盘结论转成可执行、可理解的生活提醒，不替代计算结果，也不把佛道哲学写成可验证的科学定律。

当前可用主题包括：

- **烦恼与觉察**：烦恼仍会来，但不必跟着它走；平静不是没有杂念，而是能看见念头又把心收回当下。
- **自己寻找答案**：很多答案不能由老师、伴侣或命理师代替完成，应在行动与生活反馈中自己确认。
- **日常即修行**：不把修行限定在寺院、深山或静坐；塞车、排队、洗碗、工作受阻时的反应，同样可以练稳定与觉察。
- **关系与自我价值**：关系不是用来证明自己值得被爱；靠近时真诚，放开时守住边界，不要求对方永远自动理解自己。
- **原谅与边界**：原谅不等于继续允许同一种伤害发生，也不要求反复回到旧关系。
- **情绪与自我照顾**：生气、烦躁或疲惫时先照顾自己，再处理外部问题；不把「没有情绪」误写成修行标准。

选择规则：按用户本题与 `reading.kind` 匹配，最多输出两条；职业题不塞感情鸡汤，感情题不塞工作建议，健康题不得用修心文案替代医学边界。英文版使用简明澳洲日常英语，不直译佛道术语。

## 3. 身体象义系统

身体栏采用固定三层：

- **地支固定部位**：午头、巳右肩、未左肩、辰右臂、申左臂、卯右腰、酉左腰、寅右大腿、戌左大腿、丑右小腿、亥左小腿、子下阴。
- **季令与脏腑本气**：寅卯辰看春木肝胆筋目；巳午未看夏火心神与中焦；申酉戌看秋金肺、皮肤与燥；亥子丑看冬水肾、下焦、水液与封藏。
- **六组对冲轴**：子午、丑未、寅申、卯酉、辰戌、巳亥。两端同时出现时按一条轴观察，权重大于把两端拆成两个独立问题。

当前八字报告只使用已经存在的数据：四柱地支、月令季节、当前大运地支。紫微星曜、煞曜、四化等没有接入当前 chart 引擎的资料，不得伪造。

身体栏只输出「观察区域／传统体质象／生活信号」，不得写成确定疾病、医学诊断或治疗建议。必须保留边界：象义地图不是体检；症状持续、加重或影响活动时，以实际医疗检查为准。

## 4. 内容规则

- 第一段必须直接回答原问题，不先讲方法。
- 只保留用户真的问到的主题；职业题不自动塞感情和财务，感情题不自动塞工作和财务。
- 复合问题可以在同一个总体概括里分开回答，但不得再生成额外 session。
- 命理建议只作为总体概括的末尾提醒，最多两条，不得盖过直接答案或计算结论。
- 时间／旅行题仍必须保留可执行窗口、目的地或行动顺序。
- 英文报告继续采用澳洲日常英语，不暴露 Day Master、Month Command、Ten Gods、luck cycle 等命理术语。
- 不输出内部推理、UUID、实现说明、模型状态或验收文案。
- 个人命诰图与文字报告解耦；图片失败不得阻塞文字交付。
