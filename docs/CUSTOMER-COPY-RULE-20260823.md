# Customer-facing copy rule

Front-end customer pages must show outcomes, inputs, report content, and necessary actions only.

Do not render internal methodology notes, implementation status, QA language, self-justification, process explainers, or FAQ-style filler on the main customer journey.

Examples that must stay internal:
- what is or is not connected
- why a method was chosen
- AI/no-AI implementation notes
- proof cards about engine behaviour
- report-generation design rationale
- internal visual mapping rules

The standalone Dharma Palm tool remains accessible from the homepage as a compact title + action entry.
