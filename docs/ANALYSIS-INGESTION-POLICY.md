# 昭梧｜分析知識入庫固定規則

狀態：PRODUCTION POLICY

## 默认协议锁定

自 2026-09-01 起，所有命理素材的吸收、网站分析、客户报告与内部 AI 提示词，默认先服从 `docs/METAPHYSICS-DEFAULT-PROTOCOL-v1.0.md`。紫微解释层另服从 `docs/ZIWEI-INTERPRETATION-GRAMMAR-v1.0.md`；紫微计算真值仍只由 `src/lib/ziwei/` 与其 source registry / profile 管理。

新增资料必须先分类为：

- `CALC_TRUTH`：可重现、可测试的计算规则；
- `CLASSICAL_INTERPRETATION`：可追溯古籍解释；
- `MODERN_INTERPRETATION`：近现代流派整理；
- `OWNER_MATERIAL`：站主提供的教学、实战或整理素材；
- `QUARANTINE`：疾病诊断、死亡灾祸直断、未验证数值权重、单一星曜直推重大事件等，禁止进入客户结论。

解释层不得反向修改计算真值。存在流派差异的计算规则必须保留 profile / version / provenance；不得为了“统一”静默合并。

凡站主在 ChatGPT 專案對話中提供新的命理、八字、格局、合沖刑害、病藥、身心靈、關係、因果象徵、實戰斷法或其他「分析方法／判斷口訣／案例規律」類內容，預設視為待吸收的分析素材，不需要站主每次再次說「加入」。

固定處理兩個方向：

1. GPT／專案分析庫
   - 在當前昭梧專案脈絡中視為長期方法素材，後續分析時優先回查、去重、交叉比較。
   - 保留原始說法與核心意圖，但必須區分：古籍原文、後世評注、民間口訣、站主實戰經驗、象徵性說法、待驗證假說。
   - 不得把未驗證內容冒充古籍定論或客觀科學事實。

2. 昭梧網站分析方法庫
   - 將可計算、可驗證、可形成規則鏈的部分，加入八字／格局分析方法。
   - 優先作為「分析依據／輔助判斷層」，不得覆蓋月令、日主、旺衰、格局、病藥、流通、制化、大運流年等主判。
   - 若內容適合免費版，加入免費分析依據；若涉及更深層格局、歲運、病藥、關係或象徵解讀，放入完整／付費報告層。
   - 任何規則都要保留適用條件、反例、限制與 UNKNOWN 路徑，禁止單一口訣直接推出重大事件。

## 自動整理流程

收到新分析素材後，依次執行：

原始素材 → 修正語音／錯字 → 提取規則 → 判斷來源層級 → 與現有庫去重／衝突檢查 → 定義觸發條件 → 定義禁止誤用條件 → 決定免費／付費層級 → 加入網站分析庫 → 必要時增加測試。

紫微素材额外执行：

解释素材 → 判断星曜本质／宫位场景／四化变化／辅煞过程／三方四正／岁运触发属于哪一层 → 检查是否越权成疾病或重大事件直断 → 标记 claim class → 只把可用语义进入 Interpretation Grammar；计算公式必须另走 CALC_TRUTH 审核。

## 固定安全邊界

- 醫療問題不得用命理或因果取代檢查與治療。
- 因果、業力、氣場、能量傳遞等內容若缺乏可驗證依據，只能作為象徵／傳統語言，不寫成物理機制。
- 不能因「合多、沖多、刑多、害多、墓庫、神煞」等單項指標直接判斷離婚、死亡、破產、疾病、犯罪或必然吉凶。
- 多不等於壞，少也不等於好；所有簡化規則都只是主旋律／輔助特徵，最終回到完整結構。
- 紫微单一流年、单一化忌、单一煞曜不得升级为高确定性重大事件；至少两个独立结构／时间层一致，才允许提高语气强度。
- 本命资料不可被大限、流年覆盖；岁运只作叠加、放大与触发。
- 身体模块只可输出压力倾向与生活照顾点，不可直接输出疾病名称、必手术或寿夭。

## 執行口徑

站主只要直接貼內容即可。除非內容明顯只是聊天、引用或要求不要入庫，否則預設按本政策吸收，不再要求二次確認。
