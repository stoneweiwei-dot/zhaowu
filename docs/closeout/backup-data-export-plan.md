# 資料匯出與隔離還原草案（預算 $0）

main 的手動備份只有 schema。待 #1156 審查合併後，沿用其 session pooler（5432）與資料匯出流程。零 COPY 區塊須令工作失敗。另保存來源 schema、表清單、相同一致性快照下的逐表筆數、必要角色定義及 dump 的 SHA-256。COPY 區塊存在只證明有資料段，不能證明每張表完整。

在既有免費 GitHub Actions 額度內啟用相容版本的 postgres service container，或使用本機 Docker 的一次性空資料庫。先備妥相依角色、擴充與 Supabase schema，再依 pre-data、data、post-data 順序匯入；遇 SQL 錯誤立即失敗。容器不連正式庫。逐表核對筆數（包括空表）、外鍵與序列；缺表、額外表或筆數不同均列出。Storage 二進位物件須另有清單及備份。演練報告只保留版本、摘要、筆數差異及日期。

dump 含個資。限授權人員取用，加密後存放私有 artifact，保留七天；金鑰由站主分開保管。不得提交 repo 或在日誌輸出列內容。到期前由 Stone 接收到既有加密離線媒體，回讀核對摘要、記錄交接人、日期與保留期限。若免費額度不足，採既有本機 Docker／儲存空間。此文件僅為草案，尚未執行還原或冷儲存交接。
