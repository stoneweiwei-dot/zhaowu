# 昭梧・四柱繪意完整報告契約 v2.0

內部代號：`ZW-PAID-ART-REPORT-2.0`

## 定位

昭梧完整報告 = **子平命理判斷 × 人生敘事 × 東方視覺轉譯 × 現實行動**。

本契約吸收參考報告的資訊節奏與「一人一題名、一盤一場景」方法，但不複製原畫、原文、品牌、頁面坐標、圖標或固定干支映射。它同時約束網站文字完整報告與最高檔訂製畫；兩者使用同一條證據鏈，圖片是附件，不是另一套主報告。

## 最高原則

1. **判斷先於敘事**：出生資料校驗 → 四柱 → 月令與日主 → 旺衰根氣 → 格局／十神 → 合沖刑害 → 寒暖燥濕 → 病藥／通關／流通 → 喜忌與現實驗證 → 歲運覆核 → 本題結論 → 人生表現 → 視覺象徵。
2. **首屏先回答**：原問題、1–3 句直接答案、最多一個下一步永遠在最前。藝術敘事不得延後、稀釋、重複或改寫直接答案。
3. **一份連續報告**：沿用現行 `summary/body` 保存契約；不得恢復固定九頁、十五頁冊子、七個 session 或多卡式平行結論。
4. **每個重要意象可反查**：`命局證據 → 所起作用 → 人生表現 → 視覺象徵`。
5. **能力與代價同時寫**：同一結構能做到什麼、過度使用會付出什麼，必須成對出現。
6. **文字可獨立交付**：圖片失敗、未購買或未生成時，文字報告仍然完整、可保存、可理解。
7. **象徵不是事實**：題名、瑞獸、場景與法器只是視覺翻譯，不是超自然證明或宿命斷語。
8. **結構不是平衡表**：五行不以平均為目標，十干沒有先天高下；「使命／為何而生」只轉譯為既有命局的結構功能與反覆課題。視覺、瑞獸與漫畫只可由已完成的主判往下翻譯，不可反推格局、喜用或吉凶。

## 網站實際輸出順序

完整報告只保留以下連續層級：

1. 第一屏：原問題 → 直接答案 → 唯一下一步。
2. 補充重點：最多三條真正會改變決定的理由、風險、時間或行動。
3. 一盤一景：一個專屬題名、一幅統一場景、四個職責。
4. 力量與代價：同源、並列，不做只挑好聽內容的吉祥文案。
5. 現實落點：與直接答案一致的一個行動。
6. 判斷備註：證據映射、四柱盤、歲運與其他技術內容折疊到底部。
7. 身體注意：只在相關或既有保存契約需要時顯示，並保留非醫療診斷邊界。

## 一盤一景的合成方式

最終敘事是一個場景，不是四張拼貼卡。

題名格式：`〔天地景象〕・〔核心主體〕・〔關鍵動作／法器〕`

- **天地／年柱**：只負責遠景、光線、世界尺度與外部底色；不得單獨定人格或吉凶。
- **場域／月柱**：月令與月柱放回整局後，轉成問題實際發生的環境與角色壓力；不得用單一十神貼標籤。
- **主體／日柱**：日柱、日主、根氣、旺衰與全局作用共同決定主體；不得把生肖或單柱直接換成神獸。
- **出口／時柱**：只有時辰已確認，且整局結論與現實行動一致時，才決定動勢與法器質地。時辰未知時不補造未來、晚景或固定法器。
- **當期校正**：時間相關問題必須以原局 → 大運 → 流年 → 明確指定時才流月的順序覆核。歲運只調整當期重點，不反向篡改原局。

天干先翻成質地，地支先翻成勢能，再由全局與本題決定物件。法器不得由「某干支＝某物件」死表生成；單柱意象與全局衝突時，以全局為準。

## 文字敘事契約

網站 runtime 的「一盤一景」必須輸出：

- 一個專屬題名。
- 一段統一場景，不拆頁、不拆 session。
- 天地底色、現實場域、核心主體、未來出口四個短段。
- 「這股力量能做到」與「同一股力量的代價」各一段。
- 一個現實行動。
- 可折疊的證據映射。
- 象徵邊界聲明。

敘事層只可消費已完成的 `Chart`、final reading、Question Contract 與相關歲運結果；不得自行重算四柱、製造新格局、提升 provisional 喜用或增加本題沒有的結論。

## 視覺交付

- 東方現代繪意 × 宋系冊頁 × 極簡象徵。
- 暖米白／象牙白／淡宣紙；輕紙纖維、顆粒與克制的舊印刷感。
- 大色塊、少色相、平面剪影、大量留白；一幅畫五層合成，不做四幅拼貼。
- 主體清楚、環境克制、法器最多一件。
- 9:16 iPhone 優先；PDF／A4 重新排版，不直接拉伸。
- 先生成乾淨畫面，再由程式疊加 `STONE 原創`。
- 圖像失敗不得阻塞文字答案、完整報告、保存或交付。

## 禁止

- 把參考報告的十五頁結構或原版式搬進網站。
- 恢復固定九頁、編號章節、七個 session 或多套互相競爭的報告。
- 看到壬就直接畫水、看到寅就直接畫虎，或用固定表決定法器。
- 用單柱、生肖、納音、神煞或五行百分比直接定人格、疾病、財富、婚姻或喜忌。
- 把流通／調候候選升格成正式喜用，再據此要求補某五行。
- 只看流年五行就決定年度方向；跨年份沿用舊的五行圖或靈光結論。
- 「天選之人」「注定富貴」「必定發財」「必有第三者」等宿命、恐嚇或無法驗證語句。
- 為了東方感堆滿金光、粒子、蓮花、龍鳳或宗教符號。
- 在客戶成品顯示 prompt、模型、推理過程、UUID、ISO 時間戳、開發驗收句或方法狀態。

## 強制 QA

- 出生年月日時、時區、夏令時、真太陽時與時辰狀態一致。
- 四柱、日主、月令、藏干、十神、合沖刑害與相關歲運已由 canonical runtime 提供。
- 首屏直接答案仍在最前，只出現一次；唯一下一步不被藝術敘事取代。
- 完整報告仍只有 `summary/body` 兩個保存區塊。
- 一盤一景只出現一次；四個職責都回到全局，不作單柱直斷。
- 時辰未知時，未來出口明確降級，不出固定法器或晚景結論。
- 力量與代價成對；現實行動與直接答案一致。
- 每個重要意象可走完 `命局證據 → 所起作用 → 人生表現 → 視覺象徵`。
- provisional 喜用不生成硬性補五行方案。
- English 不混入漢字、BaZi 術語或中文標點式章名。
- 圖片不存在時文字仍完整；客戶層不顯示內部推理。

任何關鍵項失敗：**不得作為收費版交付。**

## 最終標準
