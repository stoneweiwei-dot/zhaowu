# 昭梧｜文章畫作與視覺素材驗收規則

狀態：ACTIVE｜2026-10-21｜適用 ChatGPT、Codex 與全部昭梧內容／網站製作代理。

## 1. 根因紀錄

2026-10-21 站主實拍證明，《三界三十一界》文章顯示四張只有標題、大數字、描線方框、漸層山形的「程式圖卡」。與 `public/articles/abhidhamma-31-realms-*.svg` 原始碼逐一相符；`src/components/life-view-home-section.tsx` 只是標準 `<img src={illustration.src}>`，未把其他照片降級重繪。**根因是 agent 選擇了錯誤的生成／提交素材，並把 SVG 語法驗證誤當圖片審美驗收。**

## 2. 先分類，後生成

- **A 繪畫／插畫**（文章配圖、繪卷、背景、佛道文化藝術、意境畫）：出圖先於排字；完整畫面要有真實場景、視覺敘事、線描、墨色及礦彩材質。預設獨立 9:16，資訊文字置於網站 HTML 區域。優先合規原創高品質 WebP/JPEG/PNG；亦可用真正藝術繪製的 SVG，不接受僅由框、字、梯度、幾何山形組成的 SVG。
- **B 資料圖／示意圖**（確實需要精確分類數字、關係或互動）：可用 SVG/HTML/CSS，優先可選取文字、手機直式布局，清楚標示它是資訊圖，不可充當新「意境畫」。
- **C UI 設計圖**：應依真實 UI 截圖／可用性測試審核，不作為成品山水畫上傳。

## 3. 四段式驗收 Gate

1. **來源確認**：圖像來源能對應實際可見的最終繪畫，非臨時 prompt 或另一張展示圖。對第三方素材確認權利與適用性；生成圖片不得憑空添加「經典原文」或錯誤天界名。
2. **素材確認**：PNG/JPEG/WebP 有有效二進位格式，尺寸、版權、色彩與畫面細節可識別；出圖不合格不進入有效素材庫；必要時先減小體積，禁止把結果變成幾何「碼圖」。
3. **引用確認**：網站代碼引用的是同一個批准圖檔；本地路徑存在，正式 URL 可載入，文章插入時不遮文字、不滾橫向。真正的插圖與圖表需要分別標示，不能誤寫成「原創畫作」。
4. **實際像素確認**：至少在 iPhone 390px 上檢視圖片及文章連續閱讀；看筆觸和主體、色彩層次、細節、是否偽文字／廉價框卡、是否完整載入。無瀏覽器實測只能回報 NOT VISUALLY VERIFIED。

## 4. 缺圖與暫用策略

正式插畫若未能安全交付 GitHub 或已批准 Supabase Storage，不要以 SVG mockup 冒充成品，不要引用外部有期限的工具下載 URL。允許暫時使用已有權利、已經存在的宋式 WebP 作**明確暫用的意境襯圖**；清楚記錄是既有作品，不得假裝是新作，也不能改寫文章宗教與科學事實。待真正的新原創圖合規入站後，再以一次性替換完成。

## 5. 自動防回退與範圍

`scripts/article-artwork-acceptance.test.mjs` 隨 prebuild 對這次受影響文章進行基本結構檢查：引用不是 SVG code card、只用同站本地且存在的 WebP/JPEG/PNG、二進位檔案魔術標頭正確、沒有四張重複素材。它**不能**取代人的像素審稿。其他記事用的真正 SVG 示意圖、命理程式化圖、互動元件仍在其合約內，不一刀切禁止 SVG。

## 6. 成本與回退

不新增第三方執行時圖片 API、沒有新 Supabase bucket/schema、沒有站外付費工具依賴。只替換文字引用，檔案由原有 CDN 緩存供應。失敗時文章文字保持可讀；回退只需還原來源檔引用與規範變動，不刪客戶媒體。
