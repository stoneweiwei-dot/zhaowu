# 昭梧｜今日色意 ZW-DAILY-COLOR-INTENT-1.0

## 產品位置
- 首頁第一個「今日指引」內的第二頁：**今日色意**。
- 完整互動指南：`/daily-colors`。
- 不另建獨立產品線，不進正式命書主判，不新增付費牆。

## 核心問題
> 今天的我，需要被提醒成為什麼樣的人？

不是問「哪個顏色最幸運」，也不是用顏色替代命盤判斷。

## 固定邏輯
1. 黃曆只提供一個**輕量參考色**：依今日日干五行映射為 木→綠、火→紅、土→棕、金→金、水→藍。
2. 這個映射不是喜用神、不是補五行、不是個人幸運色，也不得反向改寫八字主判。
3. 使用者的當下需求與個人色彩記憶優先，可以隨時改選。
4. 十四色固定為：紅、橘、黃、綠、藍、水藍／藍綠、紫、粉紅、棕、黑、白、灰、金、銀。
5. 每色固定四層：**核心象徵｜適合現在｜什麼時候少一點｜今日提醒**。
6. Color Magic 無唯一絕對對照表；前台必須保留「象徵工具、非固定結果」邊界。

## 前台禁用語
不得宣稱：
- 穿某色一定招財、改運、避災、治療、保護或成功；
- 五行缺什麼就穿什麼；
- 日干參考色等同個人喜用神；
- 顏色能取代現實決策或專業建議。

## 手機 UI
- iPhone 390–430 px 優先。
- 十四色選擇使用直式雙欄；不得要求左右拖卡。
- 每個觸控目標至少 44px。
- 點色後在同頁顯示四層內容，不跳新頁。
- 圖片、動畫不是依賴；文字本身必須完整可用。
- 繁中、簡中、英文三語同功能，英文用自然澳洲英語。
