# 六道习气测验 acceptance checklist

1. 首页出现「六道习气测验」入口并进入 `/quiz/six-realms`。
2. 页面明确把六道作为每日／当下心境观察框架，不宣称测出死后去处或前世身份，也不替代正式一掌经。
3. 六题均为整行可点击单选；当前题未选择时下一题 disabled。
4. `AAAAAA` → 天道习气为主导心境。
5. `BBBBBB` → 阿修罗道习气为主导心境。
6. `CCCCCC` → 人道习气为主导心境。
7. `DDDDDD` → 畜生道习气为主导心境。
8. `EEEEEE` → 饿鬼道习气为主导心境。
9. `FFFFFF` → 地狱道习气为主导心境。
10. `AAABBC` → A 为主导心境、B 为次要心境；不把低分 C 冒充第二名。
11. `AABBCC` → A/B/C 主导并列，不强行挑一个，也不虚构次要心境。
12. 结果页同时解释当前习气、容易卡住的地方与转念方向，并保留完整六道计分。
13. 无登录、生日、AI、付费依赖；结果不写入正式命盘或付费报告。
14. 锁定的八字、一掌经、auth、payment 和 actions 文件未修改。
15. iPhone Safari 无白屏、卡死、横向滚动：待 CI / Production 浏览器验证后填写。
