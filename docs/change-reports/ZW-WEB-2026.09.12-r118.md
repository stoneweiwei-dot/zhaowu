# 昭梧更新報告｜ZW-WEB-2026.09.12-r118

## 本次改動

- 「今日靈籤」移除登入與已保存生辰限制；未登入訪客可在首頁每日黃曆的「今日指引」中直接抽取。

## 影響範圍

首頁每日黃曆中的今日靈籤入口、公開文案與 PWA cache。
