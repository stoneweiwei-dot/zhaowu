# 昭梧更新報告｜ZW-WEB-2026.09.19-r158

## 本次改動

- 首頁移除「七種個人分析」與七個公開流派／專卷入口。
- 客人保存出生資料後，在同一個四柱區域直接看到一份連續完整綜合報告。
- 綜合報告固定整合為：核心底盤、性格與內在節奏、關係與互動、事業與資源、人生階段、反覆課題與現實行動。
- 子平八字維持唯一結構主判；其他專項引擎只在內部產生旁證，不在前台展示流派名稱。
- 原專項 routes 與 deterministic engines 保留作內部能力與回歸驗證，沒有刪除計算資料。

## 為什麼改

站主先前已確定「單一整份報告」方向：不同流派只在後台各自處理擅長的專項，報告組裝層必須合併成一份白話正文。現行首頁又露出七張獨立入口，令客人需要自行選派系，也讓首頁重複、分散。本版恢復單一交付流程。

## 影響範圍

- 首頁出生資料、四柱命盤、基礎解釋與後續提問流程。
- 首頁七個專卷入口的可見性。
- 綜合報告的前台閱讀結構與手機排版。
- 公開 release metadata 與 PWA cache 版本。

## 受保護範圍

- 不修改四柱、節氣、真太陽時、藏干、十神、起運與大運等 calculation truth。
- 不修改紫微、西占、印度古法、七政、一掌經與生命靈數的既有計算函式。
- 不修改問題型完整報告、登入、付款、Supabase schema、歷史報告或站主音樂。
- 不把旁證提升為子平主判，也不把流通候選冒充正式喜用神。

## 驗證狀態

- 待本 release 的 Production CI、Vite build、TypeScript 與 iPhone Safari gate 完成。
- 待 Netlify Production 發布後，以首頁實際生辰流程確認：七入口消失、完整綜合報告自動顯示、提問仍可使用。

## 回滾

回滾本 release 的首頁 route、`UnifiedBirthReport`、`AnalysisForm` 接線、design-system CSS、tests 與 r158 release metadata，即可恢復 r157 的七入口畫面。回滾不涉及資料 migration 或任何客戶資料刪除。
