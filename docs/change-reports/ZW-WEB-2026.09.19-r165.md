# 昭梧更新報告｜ZW-WEB-2026.09.19-r165

## 本次改動

- 將首頁核心產品名稱收斂為「昭梧命書」，不再以「很多工具／很多流派」作為客戶第一印象。
- 核心流程固定為：錄入一次生辰 → 規則引擎排出四柱 → 顯示基礎底盤 → 生成一份連續昭梧命書 → 沿命書繼續提問。
- 將既有內部多法交叉機制改成客戶可理解的透明說明：子平八字負責結構主判，其他專項只在後台交叉旁證，不反向覆蓋主盤。
- 明確分離「排盤」與「解讀」：四柱先由確定性規則計算，後續解讀不自行重算或改寫命盤。\n- 在同一條命書流程內新增「命盤資料與核對」：可一鍵複製 AI 可讀命盤資料包，查看鐘錶時間／真太陽時／時區／排盤來源／時柱校驗狀態，並直接進入版本更新記錄。\n- 核對頁面只聲明可重現的工程事實：固定回歸案例與核心流程 Gate 用於偵測計算或邊界規則漂移，不把 CI 通過包裝成「命理解讀必然正確」。
- 保留 r163／r164 已收口的宋式宣紙視覺、日夜模式、青玉小龍單一浮動入口與播放器整合，不再另開視覺分支。

## 為什麼改

本版以三類成熟競品能力作收線參考，但不複製其品牌或畫面：
- 吸收個人命書類產品「一次錄入、一路讀完」的報告動線；
- 吸收 FateBook 類產品把命理解讀做成可感知、可持續閱讀的「一本命書」產品感；
- 吸收工具型平台對「規則排盤、AI／解讀層分離」的技術透明度。

昭梧最終仍維持自身定位：高級宋式紙本體驗、子平主判、跨法旁證、單一連續報告，不變成工具超市。

## 影響範圍

- 首頁 Hero 文案與產品定位
- 出生資料 → 四柱 → 命書 → 問答的客戶可見文案
- 統一綜合報告標題、說明與方法邊界\n- AI 可讀命盤資料包、計算口徑、核對方法與版本追溯
- 公開版本資訊與更新頁

- 紫微、七政、西占、印度占星、一掌經等專項計算 truth
- Auth、付款、Supabase schema、站主後台
- 青玉小龍播放邏輯、音檔與拖曳行為
- r163／r164 canonical design system
