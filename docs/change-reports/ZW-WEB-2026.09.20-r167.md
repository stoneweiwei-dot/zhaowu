# 昭梧更新報告｜ZW-WEB-2026.09.20-r167

## 為什麼改

站主檢視 r166 正式首頁後判定整體過於寡淡。實際畫面雖已能辨識宋式遠山，但米白遮罩、標題、卡片與控制項的色階過於接近，品牌缺乏重量與層次。

## 本次改動

- 降低背景洗白遮罩，提升遠山的礦物色、墨線對比與空間深度。
- 主標與核心小標改用更深的松綠與赭金，拉開印刷層級。
- 核心紙面加入鎏金細邊、松綠頂線與低強度紙面陰影；仍保持不透明暖米宣紙。
- 延伸入口加入少量朱砂邊線，避免全頁只剩米白與灰字。
- 主要按鈕加深為松綠底、金色細邊；表單焦點使用克制的金色輪廓。
- 夜間模式保留低亮度山景，不再只有一整片扁平深綠。

## 影響範圍

- 首頁日間／夜間表面視覺。
- 首頁標題、主要表單紙面、按鈕、欄位與三個延伸入口。
- 公開版本資訊與視覺契約測試。
