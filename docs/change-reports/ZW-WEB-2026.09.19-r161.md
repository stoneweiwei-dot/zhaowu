# 昭梧更新報告｜ZW-WEB-2026.09.19-r161

## 本次改動

- 修復 Netlify `Request` 的 JSON body 被誤認為已解析物件，導致正確站主密碼 `19881004` 在 Production 被判錯的問題。
- 首頁五秒開場加入明確「開啟聲音」控制；登入背景影片加入同一套使用者手勢聲音控制。
- 首頁主線改為「出生資料 → 命盤 → 完整綜合報告」置頂；今日、心境小測、吉象圖鑑、觀世錄統一為四個預設收起、同時只開一個的延伸區。
- 右上角日／夜切換不再顯示裝飾圖示，改為可直接辨認目前狀態的文字分段。

## 為什麼改

正式 Netlify 函式可收到 POST，但標準 `Request.body` 是 `ReadableStream`；舊判斷把它直接當成 JSON，實際密碼因此永遠為空。首頁同時混用常駐、`details`、局部展開與多層卡片，造成手機版閱讀順序不明。開場影片本身沒有音軌，登入影片則被瀏覽器自動播放規則靜音，所以必須提供使用者手勢控制。

## 影響範圍

- `/api/owner-login`
- `/` 首頁資訊架構、首頁開場、Header 日夜控制
- `/login` 動畫聲音控制與站主密碼欄位文案
- 手機與桌面首頁視覺

## 受保護範圍

- 不修改站主密碼內容、Cookie 名稱、權限模型或 Supabase Auth。
- 不修改八字／紫微／占星計算、完整報告內容、歷史紀錄、付款、Supabase schema 或媒體原件。
- 保留既有測驗、圖鑑、文章、黃曆與天象功能，只統一首頁入口與展開狀態。
