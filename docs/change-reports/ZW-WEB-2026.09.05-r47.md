# 昭梧更新報告｜ZW-WEB-2026.09.05-r47

## 本次改動

- 首頁新增 r47 美術收斂層，沿用既有宣紙系統，不重做產品結構。
- 今日黃曆由偏冷灰白卡片改為暖米宣紙、淡玉綠霧與低對比赭色紙紋。
- 首頁主操作統一為松綠，朱紅退回印章、眉題、箭頭與重點提示用途。
- 問事表單改成一張連續紙面：降低大白卡與厚陰影，統一輸入框、標題、編號、焦點狀態與提交按鈕。
- 四門與趣味入口降低獨立卡片感，改成同紙面分區與細線層級。
- iPhone 版縮窄外框、降低圓角、保持輸入字級 16px，避免 Safari 自動放大並改善首屏密度。

## 為什麼改

現有 r46 已整理好首頁閱讀順序，但視覺仍偏現代灰白卡片，與昭梧既定的米白宣紙、松綠、朱印、宋系東方感存在落差。r47 只調整呈現層，讓首頁看起來像同一張完整紙面，而不是多塊 UI 卡片拼接。

## 影響範圍
