# 昭梧更新報告｜ZW-WEB-2026.09.20-r166

## 本次改動

- 把首頁固定宋式遠山由「幾乎看不見」調整為肉眼可辨識的低權重背景。
- 保留暖米宣紙遮罩與不透明內容紙面，背景不穿透表單、命盤或報告文字。
- 首頁移除「吉象圖鑑」延伸入口，並停止在首頁載入圖鑑元件與素材請求。
- 獨立 `/auspicious-atlas`、圖庫原件、報告相容引用與站主管理功能全部保留。

## 為什麼改

r163 的背景遮罩達到 90–94%，雖然程式仍載入遠山，但正式畫面肉眼看起來接近純色宣紙。r166 提高遠山辨識度，同時維持內容紙面的清楚與高級感。現有圖鑑內容不足，因此先從首頁主動線退出，避免空入口與不必要載入。

## 影響範圍

- `/` 首頁背景強度與延伸內容入口。
- 首頁不再載入 `AuspiciousGallerySection`。
- 公開版本資訊與更新頁。

## 受保護範圍

- 不刪除任何圖庫原件、資料列、既有報告圖片或站主管理能力。
- 不修改登入動畫、青玉小龍、命理計算、auth、付款、Supabase schema 或使用者資料。
- 不改獨立 `/auspicious-atlas` 與站主 `/gallery` 路由。

## 驗證狀態

- 合併前必須通過 Deploy gate、Engine suite、iPhone Safari、TypeScript 與 Vite production build。
- 合併後核對 Netlify Production 精確 commit、首頁背景計算樣式與首頁 DOM 不含圖鑑入口。

## 回滾

回滾 r166 即可恢復上一版背景遮罩與首頁圖鑑入口；本版沒有資料庫 migration、媒體刪除或不可逆操作。
