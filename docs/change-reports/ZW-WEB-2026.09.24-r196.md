# 昭梧更新報告｜ZW-WEB-2026.09.24-r196

## 本次改動

- 完整綜合報告新增「完整命書／漫畫 Lite」切換，預設先顯示漫畫 Lite。
- 漫畫 Lite 把同一份報告排成六格：核心底盤、性格節奏、關係互動、事業資源、人生階段、反覆課題與行動。
- 每一格顯示主線，並可展開完整原文；切回完整命書時仍保留原來所有段落與既有漫畫插頁。
- 手機版改為單欄六格，390px 下維持可讀文字與可點按控制。

## 為什麼改

r188 只有三處漫畫點綴，還不是可完整閱讀的漫畫版本。本版把漫畫變成一個真正可選的完整報告閱讀模式，同時保留正式命書與全部原文。

## 影響範圍

- 首頁生成完整綜合報告後，預設顯示漫畫 Lite 六格。
- 使用者可切回完整命書，或在任一漫畫格內展開完整原文。
- 更新頁與公開版本號升至 r196。

## 受保護範圍

- 本版只改報告閱讀與美術呈現，不改四柱排盤、曆法、格局、旺衰、病藥、流通或任何專項計算。
- 不新增、不修改 payment／paywall／checkout／paid visual provider。
- 不改 Auth、Owner Cookie、Supabase schema、Storage 或既有報告資料。
- 漫畫 Lite 直接重用 unified report 的輸出，不另存一份縮水報告，也不產生新的計算真相。

## 登入影片後台核對

- 正式站站主登入回應正常，`/api/owner-session` 回傳已驗證。
- 同源 `/api/owner-data` 可讀取 `loading` 素材。
- 現有資料中沒有 MP4／WebM 登入影片；23 條帶 `login-background` 的歷史資料為 PNG／JPEG，會被目前影片專用管理介面排除。

## 驗證狀態

- r188 + r195 漫畫契約測試。
- Deploy gate、TypeScript 與 Vite production build。
- GitHub Engine suite 與 iPhone Safari gate 合併後執行。
