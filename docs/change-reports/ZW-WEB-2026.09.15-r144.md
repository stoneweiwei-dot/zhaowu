# 昭梧更新報告｜ZW-WEB-2026.09.15-r144

## 本次改動

- 普通訪客退出會員 Email／註冊流程，恢復手機／瀏覽器裝置本地訪客模式；出生資料繼續使用 `zhaowu.birth-record.v1` 保存在本機。
- 獨立站主登入完整保留：`/login` 只提供站主密鑰，仍使用安全 HttpOnly Cookie，不改站主權限模型。
- 首頁分析流程改回兩段：先填／確認出生資料，保存後才顯示提問區；已有本機生辰時直接進入提問階段。
- 恢復問題輸入與真正的 `analyzeLife` 執行，不再只有「保存生辰」而沒有問事入口。
- 第一屏答案改成 answer-first：原問題 → 直接答案 → 一個最重要下一步。命盤與人物分析移入可展開的「查看命盤依據」，避免資訊同層堆疊。
- 新增最後一層 question relevance guard：若答案沒有真正覆蓋使用者問題，就停止補模板，改為誠實輸出目前能支持的相關結論；同時去重並限制無關句子擴張。
- iPhone Safari 流程與既有 r139／guest-first 契約測試同步改成 r144 現行行為。
- PWA cache 升至 `zhaowu-shell-r144`。

## 為什麼改

站主要求普通使用者回到先前「手機直接使用」的體驗，只保留站主登入；並明確要求出生資料填完後再出現提問區。此前 r139 將會員登入／註冊重新放回 active path、同時移除首頁問事區，已與最新產品意圖衝突。

另外，舊回答頁把直接答案、命盤、命象、裝飾性文案與多個技術區塊放在同一閱讀層，容易讓真正答案被大量資訊淹沒。r144 將專業度的優先級改成「先回答問題，再給必要依據，再給下一步」，而不是展示越多模組越好。

## 影響範圍

- `/`：出生資料 → 提問 → 結果的主要使用流程。
- `/login`：普通會員入口退出 active path，只保留獨立站主登入。
- 全站 AuthProvider：不再恢復普通 Supabase member session；普通訪客按裝置本地 guest 處理。
- 問答輸出：新增最終問題相關性 QA；結果首頁改成精簡 answer-first 版面。
- PWA／iPhone Safari：更新快取與回歸契約。

說明：「手機登入」按歷史實碼恢復為裝置本地識別／localStorage，而不是把 IP 位址當帳號。行動網路 IP 會輪替、NAT 共用，不適合作為可靠個人身份，因此 r144 不新增 IP 身份認證。

## 受保護範圍

本次不修改：

- 四柱、節氣、藏干、十神、起運、大運等 deterministic Bazi calculation truth；
- R6.2.1 + P2 命理主判規則；
- D60 計算公式與可靠度 Gate；
- 紫微／西占／印度占星確定性計算；
- Supabase schema、使用者資料或既有 Storage 原始資料；
- 付款流程；
- 站主密鑰 hash、Cookie 安全屬性與站主權限邊界；
- 背景音樂、圖庫、Loading、Logo 等與本次無關功能。

## 驗證狀態

合併前必須通過：

- Deploy gate；
- Engine suite；
- iPhone Safari；
- 首頁普通訪客無公開會員登入 CTA；
- `/login` 只顯示站主登入；
- 生辰未保存前不顯示問題，保存後顯示問題；
- 問題提交後能產生 `#result`，直接答案可見、技術依據預設收合；

未通過上述 Gate 前不得聲稱完成。

## 回滾

若 r144 導致分析入口、站主登入、iPhone Safari 或問答結果回歸，回滾本 PR 的 r144 變更即可。不得藉回滾恢復被最新站主指令明確取代的會員登入產品意圖；若只需修正單一 UI／QA 問題，優先做最小修復而不是整體退回 r139。
