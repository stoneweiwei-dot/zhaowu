# 昭梧更新報告｜ZW-WEB-2026.09.07-r78

## 本次改動
- 首頁「直接問事」與「四柱八字」拆成兩個獨立主分區，四柱八字不再混在其他命理入口。
- 出生年月日、時間、地點與必要個人欄位改為全站共享記錄；填寫一次後，紫微、七政、天機、一掌經等需要生辰的頁面直接沿用。
- 報告母圖移除厚框、圓角照片卡與相框感，統一改為宋系宣紙圖文融合。
- 已安裝到 iPhone 主畫面的 PWA 會在重新開啟、回到前景與 Service Worker 更新時主動取得新版本，不再把「刪除主畫面捷徑再重新安裝」當作更新流程。
- 修正首次安裝 Service Worker 取得控制權時的刷新競態，避免第一次進站被無意刷新離開當前路由。

## 為什麼改
站主已明確要求昭梧的出生資料只填一次、四柱八字獨立成主區、網站視覺以宋系宣紙美術系統為主，同時要求既有 iPhone 主畫面安裝可以自行更新。這一版把前面分散完成的修改收口成同一個正式發布基線。

## 影響範圍
首頁、出生資料共用層、需要生辰的專門方法頁、付費/免費報告視覺、Service Worker/PWA 更新流程、iPhone Safari。命理計算引擎、付款、登入與既有報告資料契約不因本次視覺/PWA收口而改動。

## 回滾
如正式站出現首頁白屏、共享生辰回歸、iPhone Safari 無法啟動或 Service Worker 更新循環，可回滾到 r75 Production，同時保留 Supabase 中既有使用者資料與 Gallery 資產，不做資料刪除。
