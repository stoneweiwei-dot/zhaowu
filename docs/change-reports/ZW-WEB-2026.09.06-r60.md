# 昭梧更新報告｜ZW-WEB-2026.09.06-r60

日期：2026-09-06 AEST

## 本次改動

- 首頁改為單一出生資料入口：出生時間與地點放在最上方，問題在後；輸入框做宣紙美化。
- 訪客與登入用戶的生辰草稿寫入本機 `zhaowu.birth-draft.v1`，登入後仍同步既有 Supabase birthData，避免各區重複填寫。
- 首頁七個體系改為只保留 title 與「主要看什麼」的解釋卡，不再從首頁進入專題完整內頁表單。
- 完整報告開頭在實際用到真太陽時或南半球時，白話說明真太陽時、夏令時與南北半球讀法。
- Header 品牌印與語言切換放大；每日黃曆依當日天干五行換色；右下角靈籤維持登入後依命理屬性開籤。

## 為什麼改

站主要求一份生辰全站共用，專題內頁不要再各自變成完整產品，否則網站過亂。真太陽時與夏令時繼續由既有後台換算，但客戶必須在報告開頭看見是否用到。

## 影響範圍

- 首頁、出生表單、黃曆小程式、Header、完整報告開頭說明、r60 CSS 與契約測試。

保護範圍：不修改 calendar.ts、chart.ts 計算、紫微／七政／一掌經引擎、登入、站主權限、付款、Supabase schema。專題路由檔仍保留舊網址相容，不再作為首頁產品入口。

## 回滾

回退本 release 相關 commits，並把 SITE_RELEASE_FALLBACK 恢復 r58。無資料庫 migration。
