# 昭梧更新報告｜ZW-WEB-2026.09.15-r135

## 本次改動

- 夜間／日間可讀性：宣紙卡片改為實色底，壁紙不再透字；夜色不再把 `text-ink` 反成月白卻留淺底，觀世錄標題與知識頁標題恢復深墨可讀。
- Header 只保留葫蘆字標 PNG 中的「昭梧」，隱藏旁邊重複的文字「昭梧」；手機標題字號與字距略收，避免黏成一塊。
- 觀世錄列表標題維持可見；損壞插圖（r134 的 webp 無法解碼）改為可解碼 SVG，並在圖片失敗時隱藏，不再出現藍色問號。
- 站主背景音樂：12MB 以內的 MP3／M4A 不再走 iPhone `AudioContext`／`decodeAudioData`，改原檔分段上傳；本機解碼加 12 秒逾時，畫面不會再停在 6%。曲庫上限改為 12MB。
- PWA shell 升至 `zhaowu-shell-r135`。

## 為什麼改

站主實機截圖顯示：夜色標題發灰看不清、Header「昭梧昭梧」重複、觀世錄只剩日期與 ＋、面相文插圖壞掉、5–10MB 音樂卡在「本機壓縮音樂，避免 iPhone 卡住 6%」。根因分別是夜色 ink token 打在未反轉的宣紙／半透明底、字標 PNG 已含「昭梧」、損壞 webp，以及略大於 4MB 的 MP3 仍被送進無逾時的本機解碼。

## 影響範圍

- 全站 Header、夜色紙面、`/knowledge`、首頁觀世錄
- `/account` 站主背景音樂上傳（`owner-music` 曲庫分支）
- PWA cache `zhaowu-shell-r135`

不修改八字、紫微、D60、西洋占星或其他命理 Calculation Truth；不復活 Supabase Audio CDN；不改普通會員登入。

## 回滾

回退本版本即可回到 r134 視覺與 r132 本機壓縮路徑。`owner-music` 已上傳曲目不需回滾。
