# 昭梧｜西方占星十章深度報告 V2.0（PR #772，開發中）

## 產品定位
本套規範以**西方占星獨立主判**、八字／紫微／印度占星可選獨立旁證為設計核心。不把西占落宮翻譯成八字十神，也不憑巧合強行互證。

既有 `/astrology` 為入口；既有 `ReportAccessGate` 為付款權限檢查，不增加裝置旗標繞過授權。
七曜舊分析沿用目前計算及報告，現代十大行星另以本站自託管 Astronomy Engine 2.1.19 計算；兩者**尚未建立同源精度驗證**，不可混稱已精準一致。

## 使用者輸入
出生公曆、當地鐘錶時分、IANA 時區（校驗 DST）、出生城市經緯度、性別（只作選填背景）、宮制。
可用宮制：Placidus／Whole Sign；現有舊引擎另有 Equal，但目前十星 UI 未開放選用。
可用黃道：**Tropical**。Sidereal 必須另外指定 ayanamsa，經驗證前不得自行轉換；Alcabitius 也需獨立驗證後才能啟用。
地表自然季節（南北半球）、日照、生活環境可加**獨立現實環境說明**，不得修改行星黃經與星座。

## 真實數據與計算邊界
- 十行星：太陽、月亮、水星、金星、火星、木星、土星、天王星、海王星、冥王星。
- 每星黃經、逆行，可靠時間下方能判落宮；元素／模態分布僅列資料，不以分數決定性格。
- ASC、MC 依時刻與地理座標計算；Whole Sign 的 MC 不必落第 10 宮；需獨立指出其實際落宮。
- 宮頭 1–12、傳統宮主星由已有宮制結果導出；古典尊貴狀態僅按七曜及指定規則計算。
- 北交點／南交點、福點、Chiron、特殊度數（如岐度）、行運位置**尚未整合並驗證**，不得在報告捏造。
- 沒有運用戶的生活資料，不得捏造職業、親屬、關係衝突、工作機會、移居史。
- 未知出生時刻：宮位與四軸不判，對月亮日內跨星座作降級；已填寫時刻但未提供可信來源為 medium，實際出生記錄分鐘且 ±2 分鐘穩定方可列 high。
- 以真實時區校正；DST 重複或缺失的當地時間不能猜。

## 十章順序與每章依據
1. 命盤總覽：日月與可信 ASC／宮位群，先說核心主題。
2. 性格與自我：太陽、月亮、命主星及 ASC；須另驗證命主星後才能下命主星結論。
3. 事業與財富：MC、2／6／10 宮、其宮頭宮主；八字十神及紫微官祿如有已排數據才獨立註明。
4. 感情與關係：金星、火星、月亮、7 宮、關係邊界；可附紫微夫妻宮獨立資料。
5. 家庭與根源：月亮、土星、4 宮；八字年柱／月柱及紫微父母宮只作獨立旁證。
6. 身心照顧：6／12 宮、月亮、海王星；僅談生活節奏，嚴禁診斷疾病、器官或療效。
7. 精神課題：9／12 宮；交點須可核驗才可進入精神敘事，不能宣稱客觀前世歷史。
8. 未來 12–18 個月行運：需指定 UTC 當前時點、未來期間及實算行運相位；沒數據則整章標【未計算】。
9. 特殊配置：實測逆行／相位、七曜古典尊貴；Chiron、特殊度數未接不可編造。
10. 綜合建議：整合本人命盤可追溯依據與現實選擇，不產生宿命論斷。

每章必含【已計算數據】、【白話主題】、【有利面與失衡面】、【你可以這樣做】；缺資料就註明【不作判定】。
預設中英雙語：繁體中文、簡體中文、英文。10 章章名固定，可調順序；風格 direct／gentle／neutral。

## AI 報告管線（待接正式 AI provider）
`src/lib/astrology/report-protocol.ts` 匯出：
- `validateWesternReportFacts(facts)`：計算依據與欄位前置檢查。
- `buildWesternReportChapters(facts, config)`：純資料的十章個人化摘要，**不呼叫 AI**。
- `buildWesternReportPrompt(facts, config)`：封裝 AI 系統指令及證據化使用者輸入。字數目標預設 4000 字元，可設定 3000–5000；**尚未連線或授權任何模型**。

正式接 AI 時，採**伺服器驗證 entitlement → 對資料來源/輸入 schema 驗證 → 最小必要個資傳遞 → 固定 system prompt → 輸出 evidence ID 檢查 → 缺資料退回可追溯規則摘要**。
不得直接讓瀏覽器呼叫計費 AI、上傳私人命盤給任意第三方、使用未同意個資的外部背景，或在未付費狀態取得 AI 全文。
AI 可以潤飾白話和敘事，但**不能重算行星、發明時間、改動已定盤結果或跨系統硬圓**。
