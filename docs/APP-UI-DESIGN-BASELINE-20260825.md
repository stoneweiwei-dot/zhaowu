# 昭梧 App UI 設計基準

版本：`ZW-APP-UI-1.0`  
日期：2026-08-25  
參考圖：`/public/visuals/zhaowu-app-ui-concept-20260825.jpg`

## 產品定位

- 名稱：昭梧
- 用途：八字命理分析、流年趨勢與個人命盤解讀
- 主風格：宋式極簡 × 未來東方

## 一致設計系統

- 骨白／宣紙色作主底，墨黑作主文字。
- 低飽和朱砂紅只用於主要操作、選中狀態與重點數據。
- 冷金屬色只作極少量輔助，不使用黑金豪華風、紫色漸層或霓虹賽博。
- 中文標題採宋式展示氣質；功能文字採清晰現代 UI 字體。
- 細分隔線、明確網格、充足留白、小圓角元件。
- 手機優先，文字、分析圖與操作按鈕必須可讀、可點、不卡首屏。

## 四個基準畫面

1. 歡迎頁：昭梧品牌字、印章抽象符號、單一進入操作；禁止攝影照片。
2. 首頁：每日概覽、五行資訊與主導航。
3. 八字命盤：四柱結構、五行分布與命盤詳解入口。
4. 流年分析：年度趨勢、月份節奏與分類解讀入口。

## 使用規則

- 此圖是產品與前端開發對照基準，不是手機背景素材。
- 不得加入到 `zhaowu-backgrounds` 輪播，也不得裁成登入壁紙。
- 實作時沿用現有昭梧三語、登入、報告與命理計算契約。
- 視覺調整不得改動 `calendar`、`palm`、`method`、報告資料或 Supabase 權限。
