# 昭梧・四柱绘意报告风 v1.0

内部代号：`ZW-PAID-ART-REPORT-1.0`

## 定位

昭梧收费版 = **子平命理分析 × 人生叙事 × 东方视觉转译 × 私人收藏作品**。

参考《雲潭八字訂製繪畫_昭梧_》只吸收信息层级、留白、分页方式、命理视觉化方法与报告节奏；不得复制原画、原图标、原文、原版式坐标、品牌识别或固定映射表。

## 最高原则

1. **判断先于绘画**：出生资料校验 → 四柱 → 月令与日主 → 旺衰根气 → 格局/十神 → 合冲刑害 → 寒暖燥湿 → 病药/通关/流通 → 喜忌与现实验证 → 人生主题 → 视觉意象 → 最终绘画。
2. **每个重要视觉元素可反查**：命局证据 → 命理作用 → 人生含义 → 视觉象征。
3. 图像不能反过来篡改命局。文字报告删除图片后仍须成立；删除文字后最终画面仍须有统一主题。
4. 重要结构必须同时写能力与代价，禁止只挑好听的写。
5. **客户可见收费文字报告以现行 focused report 为准。** 最高档订制画是附加成像能力，不是另一套 15 页或 23 页客户报告。

## 四柱视觉职责

- **日柱｜核心本体**：日主、坐下、全局状态、现实表现；决定主体瑞兽/人物/灵物。
- **月柱｜人生环境**：月令、季节、旺衰来源、社会结构、主要运行场域；决定空间与主基调。
- **年柱｜天地背景**：根基、家族背景、早年环境、外部世界、世界观形成条件；决定天空、地貌、远景与世界色温。
- **时柱｜未来出口**：后半生趋向、创造方式、行动、作品、精神归宿、流通落点；决定道路、动作与法器。**法器必须结合全局喜用、流通与合冲刑害，不做固定“某干支＝某物件”的映射。**

## 最高档订制画生成模式（v1.1 锁定）

这一节是给客人做**最贵付费版订制画**时的唯一生图指引。吸收的是「四柱如何合成一幅画」的方法，不是原作的图库、文字与品牌。

### 一幅画的合成公式

最终交付是**一幅统一画面**，不是四张拼贴卡。

标题格式：`〔天地景象〕・〔核心主体〕・〔关键动作/法器〕`

五层必须同时出现在同一幅里：

1. **天地**：年干 = 天空气质、色温、光线性格；年支 = 远景地貌、世界骨架。
2. **场所**：月支 = 主空间类型（山庙、温泉、深林、城郭、水岸）；月干 = 这个场所的气质（精炼、温厚、冷锐、繁密）。
3. **主体**：日干 = 性情与精神质地（沉静、明烈、厚重、锋利）；日支 = 身体形态与潜能质地（瑞兽、人物、灵物的体态）。
4. **行动**：时支 = 未来空间的势态（扎根、流动、收敛、开放）。
5. **法器**：时干只提供工具的五行质地；具体物件必须由全局喜用、流通、病药与合冲推出，禁止「壬寅=罗盘」「印木=笔」这类死表。

### 天干地支如何转意象

先译「质地」，再选「形象」。

- 天干先写气质形容词：甲直、乙柔、丙明、丁暖、戊厚、己柔、庚断、辛精、壬深、癸细。
- 地支先写势能动词：寅发、卯展、辰藏、巳烈、午显、未守、申练、酉收、戌库、亥流、子藏、丑培。
- 再把形容词 + 势能落到上面五层对应的物体上。
- 若全局喜用、合冲、寒暖燥湿与单柱形象冲突，**以全局为准**，改形象而不改命局。

### 画风（昭梧原创，不照搬）

- 东方现代绘意 × 宋系册页 × 极简象征。
- 大色块、少色相、平面剪影、大量留白。
- 暖米白 / 象牙白 / 淡宣纸；轻纸纤维、颗粒、旧印刷/版画感。
- 主体清晰、环境克制、法器只一件。
- 禁止写实游戏海报、仙侠满屏金光、三国志细节堆积、四幅小图拼贴。
- 9:16 iPhone 优先；先出干净图，再叠加 `STONE 原創`。

### 客人解读口径

最高档可以附一段「画面解码」，顺序固定：

这幅画在说什么 → 年柱为何出现这片天 → 月柱为何是这个场所 → 日柱为何是这个主体 → 时柱为何是这件法器 → 这对现实意味着什么。

解码是视觉附件，不能替代 focused report 的直接答案。

## 最终合成画五层

1. 天地：年柱＋月令＋寒暖燥湿。
2. 主体：日柱＋日主＋日支。
3. 环境结构：月柱＋主要格局＋合冲刑害。
4. 行动：时柱＋流通方向。
5. 护法/法器：必须由全局命局结果推导，不能随机加宗教元素制造神秘感。

## 视觉语言

正式名称：**昭梧・四柱绘意报告风**。

- 东方现代绘意 × 宋系册页 × 极简象征主义。
- 暖米白 / 象牙白 / 淡宣纸；轻纸纤维、颗粒、旧印刷/版画感。
- 大量留白；优先“左图右文”或“一页一个结论”。
- 插画约 25–45%；正文约 15–25%；其余留白承担呼吸感。
- 画面扁平、克制、东方叙事，不做高密度仙侠海报、游戏概念图或满屏粒子金光。
- 第一眼像一本私人命理绘本/册页；第二眼才读出命局证据。

### 五行色

- 甲：森林绿；乙：翠绿；丙：橘红；丁：紫红；戊：山土金褐；己：柔土米黄；庚：亮浅金；辛：珍珠金白；壬：深 Navy；癸：浅水色。
- 颜色面积、明度与主次必须按命局作用调整，不是固定套模板。

## 排版与品牌

- 默认 9:16 iPhone 优先；PDF/A4 重新排版，不直接拉伸。
- 标题、正文、注解分级明确；不把 AI 推理过程塞进客户页面。
- 品牌：`昭梧`。
- 水印：`STONE 原創`，先生成干净图，再程序后期叠加。

## 命名系统

格式：`〔天地景象〕・〔核心主体〕・〔关键动作/法器〕`

示例：`《玄泽双库・苍渊应龙衔火珠》`

客户得到的是一件专属作品，不是一张套模板“八字插画”。

## 客户成品禁止出现

- 自问自答的分析过程。
- 开发验收句、方法路由、模块状态。
- `资料未接入`、`正式取用尚未完成` 等内部系统文案。
- 报告 UUID、ISO 时间戳、版本代号。
- 粗候选推理过程。
- “因为 AI 这样判断”等元叙事。

## 语言规则

优先写法：先证据 → 再解释 → 最后意象。

可用：`命局呈现…`、`更容易…`、`在…条件下尤其明显`、`这一结构倾向于…`、`若运行到…阶段，这一主题会增强`。

禁止：`天选之人`、`注定富贵`、`必定发财`、`一生无灾`、`某神仙转世`、`必有第三者` 等无法验证或恐吓式宿命断语。

## 强制 QA

- 出生年月日时一致；时区、夏令时、真太阳时正确。
- 四柱、日主、月令、藏干、十神、合冲刑害正确。
- 先判断全局再生成意象。
- 每个重要视觉元素有命局证据。
- 无固定标签套模板；无无依据神秘化语言；象征内容不写成事实。
- 图像与文字互相解释；文字报告可独立成立；最终画面主题统一。
- 不显示内部推理/方法状态/UUID/ISO 时间戳。
- 保持昭梧原创视觉语言；iPhone 9:16 适配；完成 `STONE 原創` 后期水印。

任何关键项失败：**不得作为收费版交付。**

## 最终标准

> 命理负责准确。文字负责理解。绘画负责记忆。最终作品负责让这个人的命局拥有属于自己的形。
