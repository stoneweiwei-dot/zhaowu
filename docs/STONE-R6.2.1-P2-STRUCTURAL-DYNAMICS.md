## P2-1｜刑沖合害破：作用先於吉凶

任何「沖、刑、穿／害、合、破」都不得直接貼吉凶標籤。

固定判定鏈：

`原局狀態 → 雙方旺衰 → 得令／得地／透干 → ODL 有路 → 作用方式 → 作用後誰增誰減 → 功能是否受損／被啟動 → 流通是否改善 → 十神／宮位／歲運落象`

硬性禁止：
- 有沖 ≠ 必凶；
- 有合 ≠ 必吉；
- 有穿 ≠ 控制／制取；
- 有刑 ≠ 必災；
- 墓庫逢沖 ≠ 必開庫。

## P2-2｜穿／害＝結構性損耗，不等於控制

穿／害先判「功能受損、關係摩擦、氣機耗散、藏干交戰」，不得寫成「我穿你，所以我得到／控制你」。

固定檢查：
1. 誰旺誰弱；
2. 雙方藏干實際作用；
3. 是否存在第三方通關、救應或放大；
4. 哪一方的實際功能受損；
5. 十神與宮位是否同步被觸發；
6. 歲運是否形成可驗證事件窗口。

禁止口訣化：
- 穿財＝得財；
- 穿官＝得官；
- 穿庫＝開庫；
- 被穿的一方必敗。

## P2-3｜TG-FS：十神本體不變，功能可偏移

十神身份由日主與干支陰陽五行關係決定。刑沖合害、制化或受損不得把一個十神「變成」另一十神。

固定三層：

`十神本體 ≠ 當前功能狀態 ≠ 最終現實象`

允許描述：
- 正印嚴重受損後，原有滋養／庇護功能失真，可呈現部分偏印／梟式象態；但仍是正印。
- 七殺被有效制化後，可呈現紀律、秩序、責任、程序化管理等類官象；但仍是七殺。

禁止：
- 「正印穿倒變偏印」作為十神真值；
- 「七殺穿倒變正官」作為十神真值。

## P2-4｜六沖＝高強度結構觸發器，不預設吉凶

遇沖固定回答：
- 沖前原本有什麼；
- 沖掉／沖動了什麼；
- 誰失根、誰得以出用；
- 是否解除合絆／閉塞；
- 是否破壞原有有效結構；
- 最終氣機更通還是更堵。

撤銷粗糙規則：
- 「沖喜神必吉」；
- 「沖忌神必凶」；
- 「衝旺喜神吉、衝旺忌神凶」。

## P2-5｜墓庫：交回動態判定，不使用機械開閉公式

辰戌丑未繼續服從 R6.1／R6.2.1 的動態墓庫判定。

固定順序：

`月令 → 庫中本氣／中氣／餘氣 → 透干 → 根氣 → 燥濕 → 合沖刑穿 → 外力強弱 → 歲運介入 → ODL 有路 → 當前庫態`

可用狀態包括但不限於：收藏、啟動、泄出、閉塞、拔根、受損、過載、結構改變；不得只用「開／閉」二分法。

禁止：
- 逢沖必開庫；
- 逢合必閉庫；
- 逢刑必開庫；
- 辰戌沖即水木自動出庫；
- 丑未沖即金自動出庫。

## P2-6｜FC：有路 ≠ 有效流通

ODL 判「功能是否被中斷」；FC（Flow Consequence）另判「即使有路，這條路是否真正完成有效傳導」。兩者不得合併。

FC 固定檢查：
1. 來源是否過載；
2. 中介是否承載得住；
3. 終點是否有根、有接氣能力；
4. 是否出現反克、回堵、過泄；
5. 最終功能是否真正完成。

示意：形式上存在 `金 → 水 → 木` 不等於流通良好；若金極旺、水承載不足、木無根，只能判「有形式通路，但有效流通不足／失衡」。

## P2-7｜神煞三級降權保持不變

神煞只在子平主結構與歲運觸發之後作旁證。

固定層級：
1. 子平主結構：月令、調候、格局、生克制化、承載、流通；
2. 歲運觸發：大運、流年、流月與原局的實際作用；
3. 神煞旁證：提示或加強象態，不得翻盤。

禁止單神煞直斷重大結果。

## P2-8｜萬物類象採非排他多重映射

不得把現實事物固定綁定單一五行。

例如「車」可從水的流動、金的機械、財的資產、印的工具／庇護、驛馬的移動性等不同層次取象；最後依問題、十神、宮位、歲運與命局結構裁決。

因此禁止作為固定算法：
- 官貴＝金；
- 文書＝火；
- 車輛＝水；
- 田宅＝土；
- 任一現實事物＝唯一五行。

類象只能是候選映射，不能覆蓋十神、宮位與主結構。

## P2-9｜跨術數同源只作哲學／語義旁證

八字、奇門、六壬、中醫、丹道可共享陰陽五行語彙，但不得宣稱運算模型相同。

禁止：
- 用奇門／六壬規則反向改寫子平計算；
- 用中醫五行直接輸出疾病診斷；
- 把「氣機」寫成已被現代物理證實的能量機制；
- 把命例反饋寫成現代統計學意義上的實證證明。
