## P3-1｜偏枯只作結構診斷，不作吉凶標籤

「偏枯」不得直接等同命差、貧命、大格、天才、災命或任何價值判決。

固定位置：

`特殊格真假 Gate → 月令／調候／根氣透藏 → 格局 → 偏枯 Gate → 病藥 → ODL → FC → 承載 → 歲運`

特殊格未先完成，不得因五行極旺／極弱而直接把偏枯升格為從旺、從弱、專旺或化氣。

## P3-2｜禁止票數判偏枯

禁止以下直接判法：
- 某五行出現幾次，所以偏；
- 某五行沒有透干，所以枯；
- 某五行在四柱字數最少，所以枯；
- 以百分比、餅圖、總分、固定倍數直接決定偏枯。

五行數量只可描述表面分布；真實判定至少同時檢查：
1. 月令／司令；
2. 透干；
3. 通根；
4. 藏干與實際可用性；
5. 合沖刑害破；
6. 墓庫狀態；
7. 作用路徑；
8. 承載與歲運引動。

禁止固定換算如「一個當令＝兩三個失令」。

## P3-3｜「偏」的定義與兩態

「偏」＝某一五行、十神或結構取得明顯主導權，並實際改變全局功能。

只能進一步判為：
- `偏而能用`：主導力量能被格局、制化、承載或流通有效使用；
- `偏而成病`：主導力量造成壅滯、過載、阻斷、失衡或破壞更高階核心結構。

硬性原則：
- 旺 ≠ 病；
- 極旺 ≠ 從旺；
- 清純 ≠ 專旺；
- 有合 ≠ 化氣。

## P3-4｜「枯」的定義與兩態

「枯」＝某一必要功能缺少有效來源、根氣或作用路徑，導致結構功能實際斷裂。

只能進一步判為：
- `枯而有源`：力量弱，但仍有根、有源、有通道或可被歲運有效引動；
- `枯而無源`：必要功能確實斷裂，且缺少可成立的來源、根氣與作用路徑。

禁止：
- 不透干＝枯；
- 字少＝枯；
- 五行弱＝枯；
- 某元素「缺」＝必須補該元素。

## P3-5｜病藥功能化

「病」不是某個五行本身。

病只允許描述為：
- 阻斷；
- 壅滯；
- 過載；
- 失衡；
- 格局破損；
- 承載不足；
- 有路但傳導失效；
- 作用鏈無法完成。

「藥」不是固定某個五行。

藥必須是能實際修復上述功能的結構或作用，且同時滿足：
1. 能制病、化病、通關、護格、泄秀或恢復承載；
2. 有實際 ODL 作用路徑；
3. 經 FC 檢查後確實形成有效傳導；
4. 不因副作用破壞更高階核心結構。

因此禁止：
- 缺什麼補什麼；
- 弱什麼補什麼；
- 某五行一來必吉；
- 某五行一來就是唯一用藥；
- 只因某元素少，就把它寫成「真正用神」。

## P3-6｜特殊格先行

從旺、從弱、從勢、專旺、化氣等必須先過獨立真假 Gate。

禁止：
- 極旺直接判從旺；
- 極弱直接判從弱；
- 五行純就判專旺；
- 天干有合就判化氣；
- 因「偏得極端」直接升格。

特殊格成立，轉特殊格處理；不成立，回正常子平格局、病藥、流通與承載分析。

## P3-7｜偏枯六態輸出

偏枯層最終只允許六種輸出：

1. `不構成偏枯`
2. `偏而能用`
3. `偏而成病`
4. `枯而有源`
5. `枯而無源`
6. `特殊格另判`

不得額外創造「大偏大貴」「極枯必貧」等宿命標籤。

## P3-8｜ODL + FC 強制聯動

偏枯判定完成後，必須依序接：

### ODL｜作用路徑
判斷是否存在生、泄、制、化、通關、承載或轉化之路。

### FC｜有效流通
即使有形式通路，仍要再判：
1. 來源是否過載；
2. 中介是否承載得住；
3. 終點是否有根與接氣能力；
4. 是否出現反克、回堵、過泄；
5. 最終功能是否真正完成。

固定原則：

`有路 ≠ 有效流通`

歲運只能引動、增強、減弱或改變原有功能；不得憑空製造原局完全不存在的結構命題。

## P3-9｜墓庫與偏枯

墓庫不得被用作「隱藏藥神自動存在」的捷徑。

禁止：
- 庫中藏某神＝該神可直接使用；
- 墓庫一沖＝藥神自動出庫；
- 逢沖必開；
- 逢合必閉。

仍按 P2 動態墓庫鏈：

`月令 → 本中餘氣 → 透干 → 根氣 → 燥濕 → 合沖刑害破 → 外力 → 歲運 → ODL → FC → 當前庫態`

沖只是一種狀態改變因素，不是開庫按鈕。

## P3-10｜五行象義使用邊界

五行象義可作二級轉譯，不得直接變成人格、疾病、職業、婚姻、財富或道德結論。

禁止機械映射：
- 水旺＝多情／搖擺；
- 水枯＝短視；
- 木旺＝固執；
- 金枯＝邊界差；
- 火枯＝抑鬱；
- 土旺＝愚鈍／保守；
- 任一單一五行狀態＝固定人格或疾病。

人事轉譯至少必須經過：

`十神 + 位置 + 格局 + 制化 + 流通 + 承載 + 歲運`

健康只能作傳統象義或壓力傾向提示，不得直接輸出疾病診斷。

## P3-11｜風水／生活五行降級

「顏色、家具、材質、水景、方位、寵物、植物＝固定五行＝可修復八字」不得進核心命理演算法。

若保留，只能標為：
- 傳統文化象義；
- 生活偏好建議；
- 低權重環境旁證。

不得宣稱其可直接改寫命局、補足用神或逆轉結構。

延續 P2「一物一行固定映射」禁令。

## P3-12｜通根與十二長生分離

「通根」與「十二長生」不得混為一談。

- 通根：判斷天干是否在地支具有可用根基與來源；
- 十二長生：作氣序、旺衰、階段性象義參考。

禁止「長生／祿／帝旺＝自動通根」的機械等號。

位置權重亦不得固定成「月支／日支永遠大於年支／時支」；位置重要，但最終仍服從月令、透干、根氣、作用鏈與實際功能。

每次輸出前追加檢查：
- 是否用五行數量／百分比判偏枯；
- 是否把不透、字少或弱直接寫成枯；
- 是否把旺直接寫成病；
- 是否把極旺／極弱直接升格為從格；
