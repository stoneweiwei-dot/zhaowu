# 五行優勢內耗測驗 v1.0

狀態：`FUN QUIZ / SUBJECTIVE SELF-REFLECTION`

路徑：`/quiz/five-element-overdrive`

## 目的

把 2026-09-15《探索未至之境》素材中「長板可能在過度使用時變成內耗」的可用部分，轉成日常行為觀察工具。

本測驗不是八字排盤，不讀出生資料，不判旺衰、喜用神、格局或吉凶；結果不得回寫正式命盤。

## 題型

- 10 題；
- 每題單選；
- 五個功能方向：木／火／土／金／水；
- 每次選擇為對應功能加 1 分；
- 最高分為主模式；
- 並列最高分時保留並列，不強行破同分。

## 五種結果

- 木｜生發型：優勢為生長、連結、開路；過度時方向過多、界線不足；下一步為修枝。
- 火｜顯化型：優勢為啟動、表達、影響；過度時急躁與續航下降；下一步為節律。
- 土｜承載型：優勢為穩定、責任、長期承接；過度時僵化與過度承擔；下一步為疏通。
- 金｜結構型：優勢為界線、決斷、品質；過度時控制與過硬；下一步為彈性。
- 水｜洞察型：優勢為觀察、策略、理解複雜性；過度時分析停滯；下一步為導流與行動。

## 固定邊界文案

「本測驗只反映目前行為傾向，不等同正式八字命盤，不判喜用神，也不會把結果寫入你的命理資料。」
