## 分卷吸收裁決
- **卷一（盲派讀象）**：理法→象法→技法、宮位優先、十神功能／宮位分層、賓主相對性及做功，可保留為低權重教學旁證；一律經 P2 的作用結果、ODL、FC、承載與禁止機械開庫檢查。
- **卷二（格局課）**：月令、調候、結構真假、病藥、清濁，可參考但不可覆蓋 CURRENT 主鏈；「格神」「病藥之藥」是編者使用的術語區分，不應聲稱等同古典《子平真詮》「八字用神，專求月令」之用神。
- **卷三（案例）**：可保留「資料已知／不可推出」的編排法；四柱錯配、大運錯序等為 QUARANTINE。既知結果的回溯最多標 VAL-C，不得混同 VAL-A 前瞻或 VAL-B 獨立盲回溯；原始事件未獨立證實者亦須標 UNKNOWN。
- **高風險案例**：疾病、死亡、司法、意外等只作傳統文化研究，不能視為醫學診斷、司法事實、已證實的事件因果或預測能力。

## 靜態錯盤：八組負面回歸樣本
下列是根據五虎遁（年干推月干）及五鼠遁（日干推時干）得出的形式不符；並非替原作者重排了真實命盤。測試檔：docs/theory-audit/lecture-v2-audit.test.mjs。

1. 第一類案例三（p30）：辛亥／癸丑 → 辛亥／辛丑（月柱形式錯）。
2. 對照一 A（p31）：庚申／辛酉 → 庚申／乙酉；對照一 B（p31）：辛巳／甲辰 → 辛巳／壬辰。
3. 對照二 A、B（p31）：丙寅／丙午 → 丙寅／甲午；其中 A 的庚申日／戊辰時 → 庚申日／庚辰時。
4. 對照三 A（p32）：甲子日／壬寅時 → 甲子日／丙寅時。
5. 對照四 A、B（p32）：壬子／癸亥 → 壬子／辛亥。

**統計**：八組不重複四柱至少一處不符；七組年／月不符、兩組日／時不符，交集一組。只可作「應拒收」的研究 QA fixture。任何真正修盤都須重新核對出生時刻、時區、節氣、十神、格局、運年，絕不能只在示例中替換一字再沿用舊斷語。

## 其他必修校勘（不可直接寫回 engine）
1. **附錄 C3（p47）**：23:00 誤稱「子正」，應為子初；又將 23:00～00:00 列為待考，口徑矛盾。保留昭梧現有日界與 profile。
2. **附錄 C4（p47）**：全世界一律以東經 120° 作真太陽時基準不成立；出生地歷史時區、DST、標準經線、均時差不可省略。
3. **附錄 C6（p48）**：「最近節或氣」與順逆數至前後節互相矛盾；未核實出生資料不得精確斷交運日。
4. **第一類案例二（p29）**：丙火以金為財、水為官殺。「寒水財重」不可直接成立；寅木生火與丙火通根亦應分辨。
5. **第一類案例二與三（p29–30）**：辛年乾造依書內法應逆排。案例二庚子月逆排為己亥→戊戌→丁酉；原文辛丑→壬寅→癸卯是順排。案例三原月干有錯，須先修月柱再另核起運，不得由錯誤原局推出真實大運。
6. **十九章／附錄 B10**：「四得」分別列為得令／得地／得助／得勢與得令／得地／得生／得助；應區分不同分類。
7. **案例 A（p35–36）**：亥、丑入辰庫、戌沖辰即開庫屬作者的盲派回溯解讀，不可違反 P2/P3 以「逢沖必開」機械定婚期。
8. **案例 D/E/I（p37–41）**：缺原始完整出生資料或大運；事故、病名、復查結論與治療成效不可由干支推定。
9. **名稱／學科**：《易經智慧》本書實質是子平八字與盲派象法，不等於《周易》六十四卦逐卦講義。
