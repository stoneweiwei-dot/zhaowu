## 一、適用範圍

這是**異獸／瑞獸畫像的預設美術指令**，不是新的八字算法，也不是對網站所有圖片一律套異獸。

- `/fun-tests?test=animal`：由 12 題結果（八種動物）與既有命局瑞獸（五種）自動組裝生成指令。沒有 Chart 只能產生「內在動物」指令，不可捏造命局瑞獸。
- 後台 `/gallery`：站主選原型和構圖，一鍵複製可給既有圖片工具使用的生成指令；不直接呼叫 API、不新增花費。
- 既有 `generate-decree-image`：**僅已判定為異獸題材**時補入宋式異獸約束；保持原有 provider owner-only、Gallery-direct、付款與 fail-open 規則。
- 後續異獸相關圖鑑、命理報告插畫、分享圖：可採用同一指令組裝器；非異獸圖片仍遵守網站原有宋式視覺權威。

**唯一程式來源**：`src/lib/song-beast-art-prompt.ts` 的 `SONG_BEAST_ART_VERSION`、`SONG_BEAST_VISUAL_DIRECTIVE`、`buildSongBeastArtPrompt`。避免各頁面自行複製另一版主指令。

## 二、主生成指令（可直接交給圖片工具）

> 昭梧 ZHAOWU｜宋式本命異獸畫像。請根據我提供的【異獸種類／既有結果】【相貌形態】【構圖：異獸獨像／主人同框／圖鑑底稿】，創作一幅**原創 9:16 竪式中國傳統畫**。
>
> **畫風**：北宋院畫工筆、宋人青綠山水、淡墨與細筆疊色；米白宣紙／絹本纖維、石青、石綠、天青、暖赭及局部微量泥金。山骨清晰、松影疏落、溪流雲水、遠近三重層次。主體輪廓準確，約三分之一以上有意義的紙面留白，詩性、悠遠、靜謐，不是冷冰冰的空白，也不是灰濛濛的模糊濾鏡。
>
> **異獸**：必須依選定物種的傳統形態創作；鹿、狐、狼、鷹、鶴、鯨、天馬、青鸞、朱雀、麒麟、白澤、應龍彼此不能共用同一張臉或鹿角翅膀模板。物種辨識優先於裝飾。
>
> **構圖 A｜獨像**：一獸一境，不出現人，偏置構圖、山水作尺度，留白引視線。
>
> **構圖 B｜同框**：人與異獸各有尺度，自然陪行／安靜守望。若要求本人相貌，必須另附照片；未附照片時只能畫虛構人物，不可自稱精確描繪真人。
>
> **構圖 C｜圖鑑**：輸出乾淨異獸主畫及可供排版的空間，標題、能力、特徵、命理註釋必須由網頁的 HTML／CSS 另行精確排字。
>
> **禁止**：黑底、暗黑粒子、金光四射、亮片與吊墜滿屏、滿版星空、閃耀魔法陣、仙俠遊戲宣傳海報、重裝鎧甲、塑膠 3D、高對比霓虹、過度混種怪獸、人工濕霧、AI 假漢字、假印章、假命理數值與圖中文字。
>
> **署名**：先生成無字底圖；網站後期按既有規則加上 `STONE 原創`，不要讓生成模型直接畫水印。

## 三、與命理 Truth Layer 的邊界

1. 內在動物是趣味問答的象徵；必須從既有作答得出，不得拿畫像倒推答案。
2. 命局瑞獸只可讀取 `deriveGuardianBeast(chart)` 的現有結果（木青鸞、火朱雀、土麒麟、金白澤、水應龍），不能自選畫得好看的物種取代原結果。
3. 生成指令不得輸出吉凶、格局、喜忌、疾病、前世身份等新事實。個別使用者無照片時不能聲稱像其本人。
4. 圖片生成是選擇性創作／站主工作流，不向所有訪客承諾即時付費生成；圖像服務失敗也不可影響測驗文字及原有正式報告。

## 四、品質／成本規範

- 9:16 首先適合手機，精確文案由三語 UI 載入；400px 左右閱讀不橫向溢出。
- 一圖一主角；同系列同筆墨、不同物種不同構圖與剪影。簽名由站內生成或後製處理。
- 已有畫作不得私自當成所有用戶專屬結果；僅能作審核通過的示例／母圖。
- 不自動啟動新的圖片供應商、付費計畫、外部儲存、資料收集或每日生成。
- `docs/ZHAOWU-SONG-AESTHETIC-FRAMEWORK.md` 仍為全站審美權威；本文件只對異獸題材加上專屬規範。
