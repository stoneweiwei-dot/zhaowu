# 昭梧紫微 Interpretation Grammar v1.0

状态：`ACTIVE_INTERPRETATION_POLICY`

本文件只定义紫微斗数的解释语法，不修改安星、宫位、四化、庙旺、大限与流年的计算真值。计算真值继续由 `src/lib/ziwei/` 的 deterministic truth layer 与 source registry 管理。

## 核心语法

> 星曜定功能 → 宫位定场景 → 四化定变化方式 → 辅煞定过程性质 → 三方四正定结构关联 → 大限流年定触发时间。

任何客户结论必须能回溯到上述链条，不得由单一星曜、单一化忌或单一煞曜直接推出重大事件。

## 四化

- 禄：输入、获得、黏合；问“什么正在进入”。
- 权：推动、控制、承担；问“什么正在被推动”。
- 科：显化、规范、认可；问“什么正在被看见”。
- 忌：收缩、阻滞、代价；问“什么正在付出代价”。

四化改变星曜功能的表现方式，不覆盖星曜本义，也不是吉凶标签。

## 三方四正

- 本宫 = 主场景。
- 三方 = 支援、资源与结构牵动。
- 对宫 = 外部反馈、张力、互补或镜像。

禁止把三方四正换算成加分、吉凶百分比或命格等级。

## 辅煞

辅曜／煞曜只改变过程性质：

- 左右：帮助、协作、转圜。
- 昌曲：文字、信息、学习、表达、规范。
- 魁钺：机会、提携、被识别、关键支持。
- 羊：直接、尖锐、切割、硬碰。
- 陀：拖延、纠缠、反复、慢性消耗。
- 火：突然、快速、爆发、短时高压。
- 铃：潜伏、累积、隐性压力、后发。
- 空劫：抽空、落差、脱离、中断、损耗、预期落空。

禁止把这些词直接翻译为炎症、肿瘤、车祸、手术等医学／灾祸结论。

## 时间叠层

本命 = 长期结构；大限 = 十年舞台；流年 = 当年触发。

内部证据语言：

- observation：单一层，只能作为观察点。
- supported：至少两个独立层一致，才可使用“较明显／较高概率”。
- reinforced：本命＋大限＋流年三层重复引动，可使用“强化／重复触发”，仍不得保证事件必然发生。

本命不可被大限、流年覆盖；岁运只叠加与激活。

## 身体解释

身体层只允许“性质叠加”：固定地支人体空间＋八字主结构＋疾厄宫场景＋主星功能＋四化变化＋辅煞压力形式＋岁运触发。

允许：压力出口、承载方式、急慢滞虚紧耗反复等过程性质、建议现实检查与生活照顾。

禁止：疾病诊断、死亡寿夭、必手术、停药、替代医疗。

## 来源治理

所有紫微资料必须分为：

- CALC_TRUTH
- CLASSICAL_INTERPRETATION
- MODERN_INTERPRETATION
- OWNER_MATERIAL
- QUARANTINE

解释资料不得反向修改计算算法。争议安星或四化必须进入 profile/version；争议解释则并存并降低确定性。

## 跨系统边界

紫微负责场景、现象与触发；子平八字继续负责月令、调候、格局、病药、流通与承载。输出固定区分【与八字一致】【紫微补充的新信息】【两套系统观察角度不同】。
