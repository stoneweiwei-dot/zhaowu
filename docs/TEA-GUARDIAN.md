# 昭梧・茶仙守护评估

状态：production candidate
路由：`/tea-guardian`

## 产品位置

- 完整报告显示后，在四个问题聚焦核心区之外，另显示「本命茶仙守护」文化体验模块。
- 茶仙模块不得加入 `composeFocusedReport`，避免把与客人原问无关的内容塞进命理结论。
- 首页单页工具区提供 7 题独立测验入口。
- 已保存的完整报告可从保存的 `engine_snapshot.chart` 重新显示相同本命茶仙；不重新排盘。

## 三个答案

1. **本命茶仙守护**：依现有命盘的月令、旺衰底盘与流通候选选型；口味只作轻量校正。
2. **当下最适合喝**：综合香气、汤感、苦涩接受度、冷暖偏好、咖啡因耐受、饮用时段与当下目的。
3. **纯口味最可能喜欢**：只看香气、汤感与苦涩接受度，不用命盘。

三者可以相同。不得为了显得「有三个答案」而故意推荐较差的茶。

## 命理边界

- 不使用「缺木喝绿茶」「缺火喝红茶」一类固定映射。
- 先把五行候选翻成命局需要的功能：温、清、开、收、流通、承托、安定，再与茶的真实制程／风味结构交叉。
- 目前正式病药、完整刑冲合害与完整岁运作用链尚未接入，因此页面只称「流通候选」，不得说成最终用神。
- 茶仙是昭梧原创文化形象，不宣称为真实宗教神祇、传承或治病力量。

## 健康边界

- 结果不是医疗、减肥、治病、保健或补运处方。
- 咖啡因高低只作相对偏好，不是实验室含量；实际含量受品种、投茶量、水温、浸泡时间影响。
- 咖啡因敏感、怀孕、服药或有既往疾病时，页面要求使用者依专业意见调整。
