# Writing Guidelines — ZHAOWU

Use [references/writing-guidelines.md](references/writing-guidelines.md) as an editorial checklist, **not as a replacement for ZHAOWU's voice and product contracts**. This is a local snapshot; source: `https://raw.githubusercontent.com/vercel-labs/writing-guidelines/main/command.md`.

## Workflow
1. Read relevant repository protocols and current content contracts; identify target audience, language, route and the existing editorial pattern.
2. Review facts, titles, information hierarchy, actionable steps, links, content types, accessibility and terminology against the local reference.
3. Preserve terminology and register across `zh-TW`, `zh-Hans`, and `en`. Native translations and mobile line wrapping matter; avoid literal translations and English-only design assumptions.
4. For metaphysics, preserve source/claim/evidence boundaries and don't present symbolic interpretations as scientific facts, medical diagnoses or certain future outcomes. For pricing, payment, access and rights, use current verified product facts.
5. Treat tone rules from the Vercel handbook as suggestions where they conflict with the owner's explicitly approved Song-style editorial aesthetic or existing wording.
6. Propose changes by file/line and modify only owner-approved pages. If content is published through CMS, do not assume a GitHub change directly updates the live page.

## Report
Give exact text changes, affected languages, factual sources, readability/translation checks and publication status. Do not claim public availability from a content draft.
