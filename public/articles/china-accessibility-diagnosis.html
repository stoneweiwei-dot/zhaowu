診斷結論：確認存在中國大陸訪問障礙

網站部署在 Vercel 平台，且首頁直接引用了 Google Fonts CDN —— 這兩者在中國大陸均存在不同程度的連通性問題。
手機端和電腦端均會受到影響，手機端因運營商 DPI 審查更為明顯。

1問題一：Vercel 域名在大陸的連通性

網站使用 xxx.vercel.app 作為主域名。Vercel 在中國大陸沒有邊緣節點（最近的為新加坡 sin1），且 vercel.app 域名及其 IP 段在中國大陸的連通性長期不穩定。

嚴重 · 根因

Vercel IP 連通性不穩定

DNS 可正常解析（中國 DNS 返回 216.198.79.x / 64.29.17.x），但這些 IP 屬於 Vercel 海外節點，中國大陸用戶到達這些 IP 的 TCP 連接經常被 RST 重置或超時。

檢測到的 x-vercel-id: sin1 (新加坡)
中國用戶請求路徑: 用戶 → 國際出口 → 新加坡節點 → 返回
無中國大陸邊緣節點
高危 · 加劇因素

vercel.app 域名被部分 DNS 污染

部分中國 ISP 的 DNS 對 vercel.app 域名存在 DNS 污染/劫持現象，解析到不可達 IP，導致頁面完全無法打開（超時或 ERR_CONNECTION_RESET）。

DNSPod DoH: 正常返回 IP
阿里 DoH: 正常返回 IP
但部分地區 ISP DNS: 可能被污染

關鍵發現：DNS 解析本身在多數情況下是正常的，問題出在IP 連通性。中國用戶能拿到正確 IP，但到這些海外 IP 的 TCP 443 連接經常被中斷。這就是「有時能打開、有時打不開」的原因。

2問題二：Google Fonts CDN 被牆（頁面級問題）

首頁 HTML 直接引用了 3 個 Google Fonts CSS 請求，以及 fonts.gstatic.com 的字體文件。Google 全系域名在中國大陸長期被完全封鎖。

方案一（P0 · 立即執行）：移除 Google Fonts，自託管字體

原理：Google Fonts 在中國完全不可達，是白屏的直接原因。把字體文件下載到項目中自行託管，徹底消除對 Google CDN 的依賴。這一步可以立即修復「白屏」問題，即使 Vercel 域名仍有波動，至少頁面加載速度不會被字體拖垮。

1

下載字體文件到項目本地

將 Google Fonts 的 CSS 中引用的 woff2 字體文件下載到項目的 public/fonts/ 目錄。

# 項目根目錄執行
mkdir -p public/fonts

# 下載 Noto Serif TC / Noto Sans TC / LXGW WenKai TC / Cormorant / Playfair / Jost
# 可用 google-webfonts-helper 工具：https://gwfh.mranftle.com
# 或直接從 Google Fonts CSS 中提取 woff2 URL 下載

# 示例：下載 Noto Sans TC Regular
curl -o public/fonts/NotoSansTC-Regular.woff2 \
  "https://fonts.gstatic.com/s/notosanstc/v...woff2"
2

創建本地 @font-face CSS

在項目中新建 src/styles/fonts.css（或直接在全局 CSS 中），用 @font-face 聲明本地字體。

/* src/styles/fonts.css — 完全替代 Google Fonts CDN */
@font-face {
  font-family: 'Noto Serif TC';
  font-style: normal;
  font-weight: 400;
  font-display: swap;
  src: url('/fonts/NotoSerifTC-Regular.woff2') format('woff2');
}
@font-face {
  font-family: 'Noto Serif TC';
  font-style: normal;
  font-weight: 600;
  font-display: swap;
  src: url('/fonts/NotoSerifTC-SemiBold.woff2') format('woff2');
}
@font-face {
  font-family: 'Noto Sans TC';
  font-style: normal;
  font-weight: 400;
  font-display: swap;
  src: url('/fonts/NotoSansTC-Regular.woff2') format('woff2');
}
/* ... 其他字重同理 ... */
@font-face {
  font-family: 'LXGW WenKai TC';
  font-style: normal;
  font-weight: 700;
  font-display: swap;
  src: url('/fonts/LXGWWenKaiTC-Bold.woff2') format('woff2');
}
/* 拉丁字體 */
@font-face {
  font-family: 'Cormorant Garamond';
  font-style: normal;
  font-weight: 600;
  font-display: swap;
  src: url('/fonts/CormorantGaramond-SemiBold.woff2') format('woff2');
}
/* ... Playfair Display, Jost 同理 ... */
3

替換 HTML 中的 Google Fonts 引用

在 index.html 中刪除所有 fonts.googleapis.com 的 link 標籤，改為引用本地 CSS。

<!-- 刪除以下全部內容 -->
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Serif+TC..." />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Cormorant+Garamond..." />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=LXGW+WenKai+TC..." />

<!-- 替換為 -->
<link rel="stylesheet" href="/fonts/fonts.css" />
4

添加系統字體 fallback

在 CSS 的 font-family 聲明中添加系統中文字體作為後備，確保即使 woff2 加載失敗也有可用字體。

/* 確保有 fallback 鏈 */
:root {
  --font-display: 'Noto Serif TC', 'Songti TC', 'SimSun', serif;
  --font-body: 'Noto Sans TC', 'PingFang TC', 'Microsoft JhengHei',
               'Microsoft YaHei', -apple-system, sans-serif;
  --font-kai: 'LXGW WenKai TC', 'Kaiti TC', 'BiauKai', serif;
}

方案二（P1 · 儘快執行）：解決 Vercel 域名連通性

現狀：即使修復了 Google Fonts，Vercel 域名本身在中國大陸的連通性仍然不穩定。需要從域名和 CDN 層面解決。

A

綁定自訂域名（必做）

使用自己的域名（如 zhaowu.app）代替 vercel.app 子域名。自訂域名可以配合中國 CDN 使用，且不受 vercel.app DNS 污染影響。

# 在 Vercel 項目設置中：
# Settings → Domains → Add Domain
# 添加: zhaowu.app (或你的域名)
# 添加: www.zhaowu.app

# 在域名 DNS 管理處：
# 添加 CNAME 記錄指向 Vercel 提供的地址
# 或使用 A 記錄指向 Vercel IP
B

在中國 CDN 前置一層加速（推薦）

在中國大陸可達的 CDN 上配置反向代理/回源到 Vercel，中國用戶請求打到中國 CDN 節點，CDN 再回源 Vercel 獲取內容。

CDN 選擇適用場景備案要求
Cloudflare China（與京東雲合作）已有 Cloudflare需 ICP 備案
騰訊雲 CDN / 阿里雲 CDN國內用戶為主需 ICP 備案
又拍雲 / 七牛雲輕量級方案需 ICP 備案
Vercel + 自訂域名（無 CDN）過渡方案域名需備案（如 .cn/.com.cn）

備案提醒：如果域名解析到中國大陸服務器/CDN，必須完成 ICP 備案。如果只是自訂域名 CNAME 到 Vercel（海外服務器），部分情況可暫時不需備案，但穩定性不保證。

C

過渡方案：Vercel + 自訂域名（最快見效）

如果短期內無法完成 ICP 備案和中國 CDN 配置，至少先綁定自訂域名。自訂域名比 vercel.app 子域名在 DNS 污染概率上更低（因為 vercel.app 本身被部分 ISP 針對性處理）。

# 最小過渡方案：
# 1. 購買域名（如 zhaowu.app）
# 2. 在 Vercel 綁定該域名
# 3. DNS 指向 Vercel（CNAME → cname.vercel-dns.com）
# 4. 同時修復 Google Fonts（方案一）
# → 預期改善：從「大概率打不開」→「偶爾慢但基本可用」
